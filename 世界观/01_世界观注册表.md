# 世界观注册表与扩展规范

> 版本：v1.3
> 定位：本文件是**唯一的世界观清单来源（Single Source of Truth）**。
> 原则：**域是插件，注册表是插槽。** 新增一个世界观 = 填一份契约 + 加一行登记，不改总纲核心章节。
> 配套：`00_总纲.md`（世界地基）、`02_域志/`（一域一文件）

---

## 一、三层结构（谁改什么）

```
00_总纲.md          世界地基：律海、天倾、客栈、系统、叙事结构。极少改动。
01_世界观注册表.md  本文件：域清单、域契约、扩展流程、三张索引。新增域只改这里。
02_域志/<域>.md     一域一文件：地理、势力、风俗、人物。新增域只加文件。
```

**改动隔离**：新增域不触碰总纲；新增流派不触碰注册表；新增题材不触碰任何设定文件。

---

## 二、层级：不是所有新想法都该成为一个"域"

| 层级 | 定义 | 载体 | 工作量 |
|---|---|---|---|
| **L0 题材** | 叙事类型，不改变世界规则 | 单元剧池 | 极低 |
| **L1 流派** | 某域内的风格/阶层差异 | 所属域文件的一节 | 低 |
| **L2 子类** | 某域力量解释下的分支表现 | 所属域文件的一节 | 低 |
| **L3 轻域** | 独立域，但有大众熟悉的原型可依托 | 独立文件 + 注册表 | 中 |
| **L4 重域** | 独立域，需要完整社会、经济、势力 | 独立文件 + 注册表 | 高 |

**预算（不是死数，是警戒线）**
- 重域：6–8 个
- 轻域：≤4 个
- 每域子类：≤4
- 每域流派：≤3
- 超限先合并或降级，不硬加。

## 三、升格五问（新增世界观必过）

| # | 问题 | 判据 |
|---|---|---|
| Q1 | 有独立的力量解释吗？ | 能用一句话说清它对律海的姿态，且不与其他域重复 |
| Q2 | 有独立的社会形态吗？ | 有自己的政权、阶层、秩序来源 |
| Q3 | 有独立的美学吗？ | 读者看三个关键词就能认出这是哪儿 |
| Q4 | 生得出故事吗？ | 至少 5 个单元剧、3 个势力、2 个招牌产品 |
| Q5 | 不抢客栈的中心吗？ | 它是客源/货源/风险，不是第二个主角 |

**判定**
- 5 问全过 → **L4 重域**
- 过 4 问 → **L3 轻域**（补齐缺项后登记）
- 过 3 问 → **L2 子类**或 **L1 流派**（挂到现有域下）
- 过 ≤2 问 → **L0 题材**（进单元剧池，不登记）

## 四、域契约（10 项，L3/L4 必填）

这是所有域共用的**稳定接口**。新增域只需填满这 10 项，就能被客栈、剧情、系统直接调用。

| # | 字段 | 填什么 | 用途 |
|---|---|---|---|
| C1 | **身份** | 名称、别名、层级、状态 | 注册表索引 |
| C2 | **定位** | 一句话（≤20 字） | 读者认知、宣传语 |
| C3 | **律海姿态** | 八选一：读取 / 改写 / 形式化 / 固化 / 借用 / 畸变 / 失控 / 蒸发 | 保证世界自洽 |
| C4 | **力量与代价** | 能做什么、付什么代价 | 战斗设计、客人能力 |
| C5 | **社会与秩序** | 政权、阶层、秩序的来源 | 政治线、势力冲突 |
| C6 | **经济与交通** | 出口、进口、货币、语言、到无籍驿的路线与耗时 | 跑商、物流、定价 |
| C7 | **美学三关键词** | 三个词，能画出画面 | 分店外观、菜品、服饰 |
| C8 | **势力** | 3–4 个，各一句话 | 剧情对手与盟友 |
| C9 | **对客栈** | 客源画像 3 类 + 招牌产品 2–3 + 风险 1–2 | 单元剧素材、菜单、货架 |
| C10 | **冲突与禁忌** | 冲突钩子 ≥5 + 不可写清单 | 剧情引擎、防止写崩 |

> **填不满就别升格。** 缺项说明它还只是个题材，不是世界观。

## 五、兼容四律（新增域不得违反）

| # | 规则 | 说明 |
|---|---|---|
| R1 | **律海可解释** | 必须能归入八种姿态之一。解释不了 → 不许进 |
| R2 | **姿态不撞车** | 同一姿态最多 2 个域（例：技术→铁枢/蒸枢；蒸发→灰原） |
| R3 | **只追加，不改写** | 新域只能以"接壤/飞地/海外碎片/新苏醒"接入，不得推翻旧设定 |
| R4 | **不抢中心** | 域服务于客栈的客源、货源、风险，不得成为第二个主角 |

### 世界内建的扩展口：天倾碎片

天倾碎裂的规则碎片**本就多于现有域**。现有八域只是"成气候的八块"，其余是错律带、飞地、孤岛、灰原。

所以新增一个域，在世界观内永远有合法位置：
- **新苏醒**：一块沉睡的碎片开始活动
- **新发现**：海外/地底/深渊另一侧，一直存在，只是没人到过
- **新拼合**：两块小碎片因故合并，长成一个新域

**这条设定保证世界观可以无限生长，而不必改写历史。**

## 六、扩展流程（七步）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 | **提案**：一句话说清是什么、从哪来 | 一行候选记录 |
| 2 | **定位试算**：用升格五问定层级 | L0–L4 结论 |
| 3 | **兼容检查**：过兼容四律 | 通过 / 打回 |
| 4 | **填契约**：L3+ 必填 10 项 | 域契约卡 |
| 5 | **落位**：地理 + 历史接入方式 | 地图位置、接入理由 |
| 6 | **试写**：写 1 个单元剧验证 | 一个完整故事 |
| 7 | **登记**：注册表加行 + 建域文件 + 三索引追加 | 正式生效 |

**第 6 步是硬门槛。** 写不出一个好看的故事，就不许登记——
