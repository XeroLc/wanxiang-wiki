# 专名总表（名词组件库）

> 版本：v1.0 ｜ 自动生成，请勿手改；改 `terms.yaml` 后运行 `python tools/terms.py export-md`
> 用途：每个专有名词是一个组件，有稳定 ID；改名用 `python tools/terms.py rename <id> --to <新名>`。
> 正文不写占位符；工具会同时改 Markdown、地图数据、站点配置和 SVG 标签。

共 **394** 个组件。

## 0. 怎么改名

```bash
# 看某个域的所有组件
python tools/terms.py list --scope 云篆洲
# 看一个组件的所有出现行（普通词/歧义名先看这个）
python tools/terms.py contexts person.banjie
# 预览改名
python tools/terms.py rename domain.yunzhuanzhou --to 苍梧洲 --dry-run
# 生效（同时改文件名、站点配置、地图）
python tools/terms.py rename domain.yunzhuanzhou --to 苍梧洲 --rename-files
# 批量改名
python tools/terms.py plan tools/rename-plan.example.yaml
```

## 2. 改名纪律

1. **先查 ID，再改名。** 不要直接全局搜索替换；同名词可能是不同组件。
2. **长词优先。** 工具已处理；手改时注意「云篆洲」与「云篆」、「骨山」与「骨山祖庭」。
3. **别名分两类。** 可替换别名跟着改；`keep_aliases`（如「九州」）不动。
4. **改完重建站点。** `python tools/build_site.py`；再跑 `python tools/check_site.py`。
5. **旧名留档。** 工具会自动写入 `former_names`，方便回溯。
