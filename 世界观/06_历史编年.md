# 历史编年

> 版本：v0.3
> 定位：回答"为什么现在是这样"。所有域志里的现状，都能在这里找到因果。
> 原则：**正史是给世人看的，野史是给读者看的，真相是给作者看的。**
> 剧透标记：【作者向】= 只有作者知道，正文暂不揭。

---

## 0. 凡例

### 0.1 纪年

- **碎历**：以天倾之年为元年，今为**碎历 3600 年**。
- **律海纪**：天倾之前，无确切纪年，史家统称"原初洪荒"。
- **洪荒余纪**：碎历 1–300 年，史家称"洪荒余纪"，太荒一域由此得名。

> 世人常把两段"洪荒"混为一谈，这是历史叙事的第一个坑，也是作者可以玩的第一个把戏。

### 0.2 史料三级

| 等级 | 名称 | 可信度 | 谁在看 |
|---|---|---|---|
| 甲 | 正史（各域官方修史） | 低——都为政权服务 | 世人 |
| 乙 | 野史（行商、游侠、说书人） | 中——细节真，因果乱 | 读者 |
| 丙 | 禁史（教会、收容队、守则局封存） | 高——但残缺 | 作者 |

### 0.3 一条铁律

**没有任何一个域的历史，是完整的。**
每一域都删掉了对自己不利的那一段——而这些"删掉的部分"，正好是主线要挖的东西。

## 2. 律海纪：原初洪荒

### 2.1 世界的样子

没有八域，没有错律带，没有国界。
只有一片**律海**，规则像潮水一样自然流淌，涨落有节。

- 生灵按"近律程度"分层：越靠近律海，越强，也越不像生物。
- 没有修行、没有科技、没有神——因为不需要。规则自己会做事。
- 那时候的"力量"，是**被规则选中**，不是**使用规则**。

### 2.2 立规者的出现

约律海纪末期，一批生灵发现了一件事：

> **规则可以被"写下来"。**

写下来的规则，会比流动的规则更稳定、更听话、更容易传给下一代。
这批人被称为**立规者**。他们是最早的"文明人"。

### 2.3 原初之城"万律"

立规者建了一座城，用来存放他们写下的所有规则。

- 城里有无数"门"，每扇门通向一种规则。
- 城的中心是一本册子，记录所有规则的账目。
- 城的名字叫**万律**。

【作者向】这座城就是客栈的前身；那本册子就是万象簿。无籍驿不是新建的，是**万律的第 N 次重启**。

### 2.4 律海潮汐

律海有周期，约**一千二百年**一次涨落。

- 涨潮时，规则浓稠，力量易得。
- 落潮时，规则稀薄，旧法失灵。

【作者向】天倾发生在一次**极枯之潮**。而碎历 3600 年，正好是下一次枯潮。

## 3. 天倾（碎历元年）

### 3.1 正史版本（甲级）

各域正史说法不一，但都含糊：

- 云篆洲：**"天失其道，道裂为八。"**
- 辉庭：**"七神震怒，焚世以净。"**
- 铁枢：**"一次不可复现的规则相变。"**
- 太荒：**"祖巫开天，天碎为骨。"**
- 无言乡：**"第一条规矩写错了。"**
- 灰原：**"没有历史。我们是被剩下的。"**

### 3.2 野史版本（乙级）

行商之间流传最广的一个说法：

> 天倾之前，有一群人想"把所有规则合成一条"。
> 他们办了一场大礼，请了所有能请的存在。
> 礼成了，天也碎了。

### 3.3 真相【作者向】

- 律海本有潮汐。极枯之潮来临时，规则本会自然收缩，世界会"缩"一圈，但不会碎。
- 立规者不甘心。他们试图在枯潮时**强行统合**所有规则，用万象簿写下"总规则"。
- 总规则与律海的"自由流动"本性冲突，产生规则层面的**回弹**。
- 回弹把律海撕成无数碎片。**天倾不是爆炸，是一次失败的"缝合"。**

### 3.4 三个后果

1. **规则分家**：碎片各自抱团，演化成八种读法。
2. **地理撕裂**：大陆被撕成八块 + 无数碎片，中间形成错律带。
3. **原初之城粉碎**：万律城碎成无数"门"，散落诸域。

### 3.5 三年沉默（碎历 1–3）

天倾之后，所有力量失灵三年。

- 修士不能吐纳，机械不能启动，神术不应答。
- 人类退回火与石头。
- 这三年里死的人，比天倾本身还多。

**这三年是所有域的共同创伤，也是所有"建国神话"的起点。**

## 4. 洪荒余纪（碎历 1–300）

### 4.1 规则碎片开始"长东西"

碎片不是死的。它们会吸附、吞噬、长出形体。

| 年份 | 事件 |
|---|---|
| 17 | 第一头巨兽出现（后来被称为"骨祖"的坐骑） |
| 43 | 第一批"兽化人"出现，血脉体系萌芽 |
| 89 | **第一位祖巫诞生**：一头巨兽吞下碎片后"站"了起来 |
| 120 | 祖巫数量增至七 |
| 210 | 祖巫数量达十二，互相划分猎场 |
| 240 | 灰原被确认为"规则真空区"，无人进入 |
| 280 | **祖巫黄昏**开始：祖巫互相吞噬 |
| 300 | 九位祖巫沉睡/同化，三位逃入律海深处 |

### 4.2 祖巫黄昏

祖巫不是被谁打败的，是**被自己吃掉**的。

- 每一位祖巫都在同化周围的一切，包括彼此。
- 打到后来，谁也说不清自己是"谁"。
- 最后剩下的九位选择**沉睡**——睡在骨山里，等规则再浓一点。

**太荒的"祖巫遗族"，就是这九位的守墓人。**

### 4.3 其他域的胚胎

| 域 | 碎历 1–300 的状态 |
|---|---|
| 太荒 | 最大碎片，巨兽与祖巫的天下 |
| 云篆洲 | 灵气细流开始稳定，第一批"引气者"出现 |
| 铁枢/蒸枢 | 同一批幸存者，靠机械取暖，尚未分家 |
| 辉庭 | 幸存者聚在废墟里，开始"向什么东西祈祷" |
| 畸城 | 少数被碎片"擦到"的人，身体开始变异 |
| 无言乡 | 碎片边缘出现第一批"会自己执行的文字" |
| 灰原 | 规则真空，无人烟 |

### 4.4 遗留物

- **骨山**：一位沉睡祖巫的尸骨，至今还在缓慢生长。
- **第一头巨兽的牙**：现存于九黎部祖庙。
- **会自己写的石板**：无言乡最早的条文，现存守则局地库。

### 5.2 第一次分炉（700）

这是铁枢与蒸枢分裂的**真正起点**，比锅炉战争早两千多年。

- **锻死派**：规则必须被压进铁里，看得见、摸得着、修得了。
- **算活派**：规则可以被写成条款，让机器自己执行。

两派分开时只是吵了一架。两千年后，他们打了一场战争。

### 5.3 灰原为什么一直没人

不是不能住，是**住了也没用**。

- 没有灵气，修不了仙。
- 没有规则，契约不成立，神术不应。
- 唯一的优势：**别人也进不来。**

所以灰原最早的居民不是拓荒者，是**逃犯**。

### 6.6 初逢之乱（1780）

**全书第一次诸域大规模接触。**

起因很小：一支太荒猎团追兽，闯进了云篆洲边境。

- 云篆洲修士用剑，太荒战士用血，两边都以为对方是"律祟"。
- 死伤过万，战线蔓延到四个域的交界。
- 铁枢与蒸枢各卖了一批武器给不同阵营——**第一次发战争财**。
- 辉庭派"调停使"，被两边同时当成奸细。

### 6.7 错律公约（1795）

打了十五年，谁也赢不了。最后签了一份东西：

> **"诸域不越界，越界者自负其律。"**

- 八域承认彼此存在，但不承认彼此的法律。
- 交界处成为"三不管"，也就是后来的**错律带**。
- 公约没有强制力，但它创造了一个东西：**中立地带**。

**这是客栈能存在的法理基础。**

### 7.2 技术裂变（2400）

锻死派的后代造出了蒸汽机；算活派的后代造出了"律契机"。

- 蒸枢：**"规则必须被锻死，才可靠。"**
- 铁枢：**"规则必须被计算，才能生长。"**

这不是技术路线之争，是**世界观的决裂**。
两域从此互认对方为"走错路的自己"。

### 7.3 无籍驿始建（2450）

建驿者是一个没有留下名字的人，史称**"无名驿丞"**。

- 位置：云篆洲西洲（芜洲）最西端，紧贴错律带。
- 目的：给跨界商队一个"两边都不管"的落脚点。
- 设计：一栋土坯房、一个马棚、一口井、一块门牌。
- 名字：官方文书作"无籍驿"；本地人仍叫"断界驿"，因为驿站在八域断口上。

**门牌上的字，至今没人认得全。**【作者向】那是万律城的门牌格式。

### 7.4 入册之夜（2760）

无言乡历史上最恐怖的一夜。

- 一座三万人的城，在一夜之间"入册"。
- 第二天，城里所有人还在，但都不再是"人"——他们成了**住户**。
- 他们照常生活、照常打招呼，只是不能离开，也不会老。

**真相**【作者向】：那城的城主想用"条文"保住全城人免受兽潮，写了一条"本城之人，永不离城"。
条文执行得比他想的更彻底。

### 7.5 守则局成立（2770）

入册之夜后，八域联手成立守则局，专门"管理条文"。

- 守则局有权张贴告示，告示即成规则。
- 但守则局自己也被一条规矩绑着：**"所有条文必须公示。"**
- 这条规矩，是后来主角能反制它的唯一缺口。

### 7.6 裂口事件（2900）

畸城地下的一次实验，把城"弄塌了"。

- 白蜡财团前身在地下研究"可控畸变"。
- 实验失控，整片城区下陷，形成**裂口**。
- 裂口深处，规则浓度异常——那是律海"漏"出来的地方。

**后果**：畸变在畸城集中爆发，畸人从此成为"城市的一部分"。

### 8.1 锅炉战争（3180–3205）

**表面原因**：煤铁资源与路权。
**真实原因**【作者向】：**规则的所有权。**

- 铁枢提出"所有机械接入枢网，由联邦统一授权"。
- 蒸枢拒绝："我烧的煤，凭什么要你授权。"
- 战争打了二十五年，双方都没赢。
- 白骨原成为主战场，至今仍有自动兵器在运转。

### 8.2 双枢协定（3205）

- 铁枢承认蒸枢的技术独立。
- 蒸枢承认铁枢的信息霸权。
- 双方互相技术封锁，史称"冷和平"。
- 战争遗物被丢在灰原，成为拾荒者的宝藏。

### 8.3 第十三军团失联（3210）

战争结束时，一支军团没有收到撤退命令。

- 他们在白骨原守了四百年。
- 靠维修战场上的自动兵器活着。
- 人已经不太像人，但军规还在执行。

【作者向】他们守的不是阵地，是一件**仍在运行的"战略兵器"**。这件东西一旦启动，会抽干灰原最后的"无律"状态。

### 8.4 律海退潮（3500）

- 云篆洲灵气整体下降两成。
- 西洲（芜洲）灵脉彻底枯竭，宗门撤走。
- 各域开始抢资源：灵脉、煤、水、粮。
- 这就是"现在很紧张"的根本原因。

**这是一次枯潮的开始，不是意外。**
按周期，它还会持续两百年——足够写完一部书。

## 14. 史料辨伪：同一件事的四种说法

以"天倾"为例，四个域的史书各写各的：

- **云篆洲《九州通纪》**："天失其道，道裂为八，非人之过。"
- **辉庭《七誓圣录》**："七神震怒，焚世以净，信者得存。"
- **铁枢《枢网年鉴》**："一次规则相变，原因不明，不可复现。"
- **灰原《荒原口传》**："那天没有神，只有一声很长的响。"

**写作提示**：让不同域的客人争论历史，是最省力的世界观展示方式，也是最自然的喜剧来源。
