# 政体总表

> 版本：v0.3
> 定位：域是洲，不是国。本表登记每域的主要政体，给政治线、商路、客源与战争一个"谁跟谁"的底稿。
> 一句话：**域管规则，国管人；客栈管两边都不管的那张桌子。**

---

## 0. 读法

### 0.1 层级

```
世界（万相界 / 拼陆）
└ 域（8 个，洲级；文化 + 规则圈）
    └ 政体（国 / 城邦 / 部落联盟 / 公司领地 / 教区 / 条文区）
        └ 势力（宗门 / 公司 / 教会 / 帮派 / 军团）
            └ 城 / 镇 / 据点
```

### 0.2 政体 vs 势力

- **政体**：领土化、主张主权。有边界、有税、有兵、有法。
- **势力**：可以跨政体。有组织、有钱、有人，但不一定主张主权。
- **一个东西可以两样都是**：青冥宗在青冥剑域是政体，在别的域只是分院；万宝楼在哪个域都不是政体，但哪个域都怕它。

### 0.3 四条约定

1. **每域列 10–15 个政体：4–8 个主要政体（详表）+ 6–7 个次要政体（简表）。** 更小的城邦、部落、教团后补，不写死数量。
2. **政体名可改。** 本表是当前快照，不是上限。
3. **"国家"只是政体的一种。** 太荒是部落联盟，蒸枢是城邦群，畸城是垂直城邦，无言乡是条文区，灰原是镇联盟 + 公司领地，辉庭是三王冠，云篆洲是仙朝 + 剑域 + 百城 + 八朝，铁枢是联邦 + 公司辖区 + 底城。
4. **每域约一个地球大小。** 本表只列主要政体；实际政体远多于此，按卷补充，不写死数量。

- 天衡仙朝是**名义共主**：它管凡人、税收、驿道，管不动宗门与边军；八朝之间打的是"正统"与"灵脉"，不是"要不要做云篆洲人"。
- **宗门是"国中之国"**：青冥宗有自己的山门、律法、灵根检测权，仙朝管不进去。
- **万宝楼、散修盟是跨国势力**，不单独建国；散修盟在芜洲有实权，但没有正式主权。
- **幽都玄朝的祖灵是"被供奉的祖先"**，不是无言乡的"条文住户"；两者不要混写。

- 无言乡**没有国家，只有条文区**；本表按"谁的地盘、谁执行条文"来列政体。
- **人间司是中立口岸，列为特殊政体**：它不称国，由住户共守，是客栈客人进入无言乡的入口。
- 守则局、城隍衙、收容队、序列教团各有自己的条文与地盘；它们之间的"边界"就是两套条文同时生效的地方。

### 2.9 域的共同利益与对外一致

| 域 | 共同身份 | 对外一致的核心利益 | 内部撕裂点 |
|---|---|---|---|
| 云篆洲 | 九州道统 | 灵脉、飞升、灵根体系 | 正统之争、灵脉分配、仙朝与宗门 |
| 太荒 | 祖巫血脉 | 猎场、兽潮、祖巫遗迹 | 部落世仇、人牲、骨山封闭 |
| 铁枢 | 契约与算力 | 枢网、信用体系、技术标准 | 联邦 vs 公司、底城、断网 |
| 蒸枢 | 炉火与工团 | 煤、炉、飞空艇、工匠传承 | 七城 vs 总工会、厂主 vs 工人 |
| 辉庭 | 七誓与圣廷 | 朝圣、圣物、教权 | 三王冠继承、教权 vs 王权、破誓 |
| 畸城 | 畸变与生存 | 抑制剂、裂口、地下秩序 | 财团 vs 帮派、畸人歧视 |
| 无言乡 | 条文 | 活人、香火、条文稳定 | 条文冲突、守则局 vs 城隍衙 |
| 灰原 | 铁路与规矩 | 铁路、水、粮、盐 | 七镇 vs 铁路公司、赏金行会 |

**三条写法**：

1. **域内是"家事"，域外是"外事"。** 八朝可以为一个灵脉打一百年，但外面的人来抢灵脉，八朝会先联手。
2. **共同身份来自共同的神话、语言与生存条件。** 云篆洲人可以说"天衡不配做共主"，但不会说"我们不是云篆洲人"。
3. **引外人打自己人，是"域奸"。** 一个政体可以借外力赢内部斗争，但一旦被坐实，它会失去在本域的全部合法性。

> **写作用法**：跨域冲突是"域 vs 域"，域内冲突是"国 vs 国"。客栈可以利用域内矛盾做生意，但不能被看成"引外人打自己人"——这是主角幕后布局最容易踩的一条红线。

## 5. 十个政体冲突钩子

1. **驿税**：天衡仙朝要收芜洲的"驿税"，客栈被夹在仙朝、散修盟与地方豪强之间。
2. **灵根检测权**：青冥剑域与南洲百城争夺灵根检测的垄断权，客栈成了双方的谈判桌。
3. **祖巫遗骨**：九黎血盟与骨山祖庭争夺一具祖巫遗骨，巫祝住进客栈，兽潮跟着来。
4. **断网审计**：铁枢联邦要审计棱镜辖区的信用分，底城趁乱断网，客栈的电子账全废。
5. **煤荒**：蒸枢七城联盟与总工会因煤荒翻脸，云港自由市趁机涨价，客栈的煤票成了硬通货。
6. **三冠继承**：辉庭三王冠的联姻变成继承战争，圣廷被迫选边，客栈的圣烛夜变成密会。
7. **抑制剂断供**：畸城白蜡辖区断供抑制剂，铁牙帮与互助会第一次联手，客栈成了唯一的安全屋。
8. **总榜更新**：无言乡守则局更新总榜，三个条文区一夜之间互相开战，人间司挤满逃难住户。
9. **新铁路**：灰原七镇联盟要修新铁路，铁路辖区与赏金行会各自押注，客栈的货道被夹在中间。
10. **做空**：万宝楼在两国之间做空货币，客栈成了唯一的兑换口，账房三天没睡。
