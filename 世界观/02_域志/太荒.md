## 1. 契约卡

- **C1 身份**：太荒，全称"洪荒遗域"。别名"蛮荒""九黎""巨兽之地"。L4 重域。
- **C2 定位**：最古老的一域，也是最不讲道理的一域。
- **C3 律海姿态**：**读取（原生）**——它不是"用"规则，它是规则的残片本身。
- **C4 力量与代价**：
  - 能做的：血脉觉醒、先天神通、兽化、蛮力、驭兽、祖巫遗法。
  - 代价：**同化**。越强，越像那块规则，越不像人。
  - 境界越高，人性越薄——**太荒的顶尖强者，很多已经不能算"人"了。**
- **C5 社会与秩序**：
  - 部落制。**力即理**：谁能打，谁的话就是规矩。
  - 三个层级：**祖巫遗族**（血脉最纯）> **大部族** > **散部与猎团**。
  - 没有成文法，只有"祖训"和"决斗"。
- **C6 经济与交通**：
  - 出口：兽材、矿石、血脉素材、巨兽骨、蛮药。
  - 进口：酒、盐、工具、铁器、布。
  - 货币：**骨贝**（巨兽牙磨的）+ 贡物 + 以物易物。铁器在太荒比钱好使。
  - 语言：蛮语（音节少、吼声多）+ 各部落土语。
  - 到无籍驿：**七日**，兽潮季不通；沿途无驿站，需自带向导。
- **C7 美学三关键词**：**血色、巨骨、雷云**。
  - 补充意象：用巨兽肋骨搭的祖庙、雷雨天祖巫遗迹会发光、战士身上纹血脉图腾。
- **C8 势力（4）**：
  1. **九黎部**：最大部族，崇尚武力，与云篆洲有旧仇。
  2. **祖巫遗族**：血脉最纯，人最少，守着祖巫遗迹。
  3. **万兽庭**：驭兽者联盟，不属任何部落，只认兽。
  4. **骨商**：跨域猎团，把兽材卖到诸域，是太荒唯一的"外交官"。
- **C9 对客栈**：
  - 客源：**血脉战士 / 巫祝 / 兽潮幸存者**。
  - 招牌产品：**蛮兽烤肉**（一份够十人）、**血酒**（烈、腥、暖）、**角斗观战席**。
  - 风险：客人酒后动手（店规要压得住）、巨兽闯店、血祭牵连、同化失控。
- **C10 冲突与禁忌**：
  - 冲突钩子：兽潮、血祭、人牲、祖巫苏醒、猎场争夺、同化失控、与云篆洲的旧仇、骨商压价。
  - **不可写清单**：不写"野蛮=落后"的廉价优越感；不写无脑蛮力碾压；不让主角靠"现代知识"驯服巨兽。

## 2. 地理

太荒是**一片没有边界的荒原**，中间散落着巨兽骸骨堆成的"山"。

| 区域 | 特征 | 谁在 |
|---|---|---|
| 血原 | 红土、雷暴多、草比人高 | 九黎部 |
| 骨山 | 巨兽骸骨堆积成山脉 | 祖巫遗族 |
| 兽海 | 万兽迁徙通道 | 万兽庭 |
| 猎场 | 各部的缓冲地带，天天打 | 散部、猎团 |
| 深渊裂口 | 传说通向律海 | 无人 |

### 2.1 骨山

- 不是山，是**一头死去的祖巫**。骨骼至今还在缓慢生长。
- 祖巫遗族住在骨缝里，靠"听骨"预知兽潮。
- 与客栈的伏笔：**骨山深处有一道门，门上的纹路和客栈招牌一模一样。**

### 2.2 雷暴

- 太荒的雷不是天气，是**规则在自我修补**。
- 雷雨后，会有新的"血脉"出现，也会有旧的"血脉"失效。
- 所以太荒人既怕雷，又盼雷。

### 2.3 兽潮

- 每三年一次大兽潮，方向不定，规模不定。
- 兽潮不是"动物迁徙"，是**规则驱动的集体行为**——它们在同化某种东西。
- 客栈若在太荒开店，兽潮就是天然的"开业劫"。

## 3. 社会与风俗

### 3.1 力即理

- 部落里没有法官，只有**决斗**。
- 有理没理不重要，站着的人说了算。
- 但有一条铁律：**不许在祖庙动武**——这是太荒唯一"神圣"的规矩。

### 3.2 血脉

- 血脉不是遗传，是**与规则的契合度**。
- 血脉觉醒要"引兽"：独自进兽海，活着回来。
- 血脉越纯，越容易被同化；同化到最后，会变成"律祟"——**长得像人，已经不是人。**

### 3.3 巫祝

- 巫祝不是祭司，是**翻译**：把律海的意思翻译给部落听。
- 他们不战斗，但没人敢动他们——**因为动巫祝的人，会被规则记住。**

### 3.4 日常

- 吃饭先割一块肉给祖先。
- 成年礼是"杀一头兽，带回它的牙"。
- 名字随血脉改：觉醒后要加一个"兽名"。
- 死人天葬，骨头留给部落做工具。

## 4. 势力详解

### 4.1 九黎部

- **表面**：最大部落，勇士最多。
- **实际**：靠对外战争维持团结，与云篆洲有百年旧仇。
- **对客栈**：最难相处，也最忠诚。一旦认你是"自己人"，会替你打到底。
- **弱点**：内部有主战派与主和派，少主压不住老战士。

### 4.2 祖巫遗族

- **表面**：守护祖庙的隐族。
- **实际**：血脉最纯，也最接近"非人"；他们知道天倾的片段。
- **对客栈**：前期不现身，中期派一个"使者"来住店。
- **弱点**：人太少，一死就断代。

### 4.3 万兽庭

- **表面**：驭兽者。
- **实际**：不认部落，只认"兽约"；谁虐待兽，谁就是敌人。
- **对客栈**：可以合作——客栈的肉食供应，离不开他们。

### 4.4 骨商

- **表面**：跨域猎团兼商队。
- **实际**：太荒唯一懂"生意"的人，也是唯一能和诸域谈判的人。
- **对客栈**：最早提出"合作"的太荒势力，但抽成极狠。

## 6. 与客栈的关系

### 6.1 客栈在太荒的难题

- 太荒人不懂"店"，只懂"营地"。
- 所以客栈在太荒的分店，外形必须是**一座大营地**：篝火、兽皮、敞开的大门。
- 店规要翻译成蛮语，第一条不是"不得动武"，是**"进了这道门，就是我的客人"**——这句话太荒人听得懂。

### 6.2 太荒给客栈什么

| 供给 | 说明 |
|---|---|
| 食材 | 巨兽肉、蛮药、血酒原料 |
| 材料 | 兽骨、兽皮、矿石 |
| 打手 | 血脉战士，最强的护院来源 |
| 故事 | 兽潮、祖巫、同化，全书最"史诗"的素材 |

### 6.3 客栈给太荒什么

| 输出 | 说明 |
|---|---|
| 一个中立地 | 部落之间不能在祖庙以外谈，客栈成了"第二祖庙" |
| 一条商路 | 骨商不用再绕远路 |
| 一种"不动武也能赢"的方式 | 这对太荒是全新的东西 |

### 6.4 主题呼应

太荒讲"谁强谁有理"，客栈讲"进门都是客"。
**这一域是主角价值观的极限测试：面对一个只认拳头的世界，规矩还立得住吗？**

## 7. 可写的故事（单元剧备选）

### 7.1 《兽潮之夜》

兽潮改道，直冲客栈。
主角不能打，只能做一件事：**把店门开得更大**。
他在门口摆了一桌肉、一缸血酒，然后坐下等。
兽潮绕开了。因为店规不是"拦"，是"待客"。

### 7.2 《人牲》

九黎部要拿一个外域俘虏祭祖，俘虏躲进了客栈。
店规"来者是客"与太荒"祖训"正面冲突。
主角必须在"得罪整个九黎"和"破自己的规矩"之间选。

### 7.3 《骨山之门》

阿骨带来一块骨片，上面刻着客栈的门。
主角第一次进入骨山，发现那道门后面，是**另一家已经倒闭的客栈**。

### 7.4 《同化》

黎烈血脉失控，开始兽化。族人要杀他，巫祝说"还有救"。
主角把他安排在客栈最里面的一间房，用"客律"压住同化。
这一夜，店规第一次"压住"了规则本身。

### 7.5 《角斗》

客栈办了一场角斗，赢的人可以免费住一年。
结果决赛是两个人都不肯赢——因为赢的人要离开客栈。
主角第一次发现：**客栈已经成了有人不想走的地方。**
