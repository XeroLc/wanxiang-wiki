# 力量体系：律海规则学

> 版本：v0.3
> 定位：世界的"物理教科书"。所有域的力量都必须能被本文件解释。
> 一句话：**万法同源，殊途异律；规则不能被创造，只能被搬运、压缩、改写。**

---

## 1. 三条基本法则

这是全世界的底层物理，任何设定都不得违反。

### 法则一：规则守恒

**规则不能被凭空创造，只能被搬运、压缩、改写、释放。**

- 修士的灵气、联邦的算法、教会的圣光、怪谈的条文，本质都是**规则的不同形态**。
- 所以"凭空造物"不存在。客栈的每一份产出，都必须有材料、人手、因果三重来源。
- 推论：**越强的力量，越依赖上游的规则来源。** 断供，就断力。

### 法则二：规则有主

**无主的规则会自我增殖；有主的规则会反过来同化持有者。**

- 无主 → 规则自己长出条文、长出领域、长出"住户"（怪谈）。
- 有主 → 规则会慢慢把持有者变成它的一部分（洪荒同化、异能畸变、序列入戏）。
- 所以**没有免费的力量，只有不同的"被吃掉"的方式**。

### 法则三：取用有价

**任何取用都要付"律价"，只是形式不同。**

| 域 | 律价的形式 | 付不起时 |
|---|---|---|
| 太荒 | 人性 | 变成律祟 |
| 云篆洲 | 因果 | 天劫收账 |
| 铁枢 | 依赖 | 断网即瘫 |
| 蒸枢 | 燃料与维护 | 炸炉 |
| 辉庭 | 誓约 | 破誓反噬 |
| 畸城 | 身体与精神 | 变成畸物 |
| 无言乡 | 自我 | 入册成住户 |
| 灰原 | 无（也没有力量） | 命最贱 |

**律价不是惩罚，是物理。** 就像烧火要耗柴，不是火在惩罚你。

## 2. 规则的四要素

任何一次"施法/开机/祈祷/发疯"，都可以拆成四项。写战斗时按这四项检查，就不会写飞。

| 要素 | 问什么 | 例（客栈店规） |
|---|---|---|
| **载体** | 规则依附在什么上？ | 门牌、契书、招牌、店本身 |
| **形式** | 规则以什么形态存在？ | 条文（文字） |
| **权限** | 谁能调用它？ | 东家、掌柜、持牌人 |
| **代价** | 调用要付什么？ | 东家自己也受约束 |

**四要素缺一，力量就不成立。** 这是防止"主角突然会了新招"的检查表。

## 3. 八种姿态的机制

八域不是八种力量，是八种**取用规则的方式**。

| 姿态 | 动作 | 规则来源 | 代价 | 失效条件 | 典型 |
|---|---|---|---|---|---|
| **读取**（太荒） | 直接承受原生规则，让规则住进身体 | 律海原生残片 | 同化，越强越不像人 | 血脉稀释、雷雨改规则 | 祖巫、凶兽 |
| **改写**（云篆洲） | 把规则炼进自身，改写成"我的道" | 灵气（律海细流） | 因果、天劫 | 灵脉改道、道心崩 | 真君、宗主 |
| **形式化**（铁枢） | 把规则写成条款、算法、协议，交给机器执行 | 律契与算力 | 依赖基建与授权 | 断网、断供、权限回收 | 联邦院士 |
| **固化**（蒸枢） | 把规则压进压力与机械，锻死 | 煤、铁、压力 | 燃料、维护、工匠 | 断煤、炸炉、工匠断代 | 工团主席 |
| **借用**（辉庭） | 向有主规则求取，以誓约作抵押 | 神/血脉/圣物 | 誓约反噬、神明沉默 | 破誓、教义分裂 | 教皇、圣骑士 |
| **畸变**（畸城） | 规则直接长在个体上 | 个体与律海的偶然接口 | 身体与精神畸变 | 情绪失控、断药 | 畸王、畸物 |
| **失控**（无言乡） | 规则脱离载体，自我增殖、自我执行 | 律祟 | 被条文吞噬 | 违规、条文更新 | 无名之物 |
| **蒸发**（灰原） | 规则缺席，只剩物理 | 无 | 无超凡，寿命短 | —— | 枪王、警长 |

### 3.1 为什么只有这八种

因为"取用规则"只有四个动作：**读、改、借、压**。
再加三个失控态：**畸、祟、无**。
以及一个原生态：**读（原生）**。

不是我们挑了八个题材，而是**这八个位置在逻辑上是穷尽的**。
未来新增的域，只能落在这八个位置的组合或变体上——这就是注册表"姿态不撞车"规则的物理依据。

## 4. 跨域规则力学

### 4.1 规则密度

| 区域 | 规则密度 | 效果 |
|---|---|---|
| 域内核心 | 高 | 本域力量 +，外域力量 − |
| 域内边缘 | 中 | 本域力量持平 |
| 错律带 | 混乱 | 所有力量不稳，随机增强或失灵 |
| 无主墟 | 极乱 | 规则互相撕扯，物理法则也不稳 |
| 灰原 | 零 | 所有超凡失效，物理唯一可靠 |

**"规则密度"是全书最重要的环境变量。** 同一场战斗，换个地方，胜负可能相反。

### 4.2 兼容与冲突

- **兼容** → 共鸣：两套规则互相借力，效果叠加。跨域合作的基础。
- **冲突** → 律蚀：规则中毒，轻则力量紊乱，重则变成半规则生物。
- **临界** → 律压：两域挤压形成的"规则高压"，会把人压成"规则的形状"。

## 5. 规则位阶：统一度量

八域境界无法直接比较，所以引入一个中立刻度：**规则位阶 R0–R9**。

**它不是战斗力，是"能改动多少规则"。**
位阶高 ≠ 一定赢，因为还要看环境密度与规则兼容。

| 位阶 | 能力 | 一句话 |
|---|---|---|
| R0 | 无 | 凡人，只能使用工具 |
| R1 | 感知规则 | 看见"气"，但改不动 |
| R2 | 借用规则 | 借一小块规则为己用 |
| R3 | 稳定改写 | 能把规则固定成"术/器/约" |
| R4 | 局部立法 | 在小范围内立一条规则 |
| R5 | 领域成形 | 规则覆盖一座院落/一条街 |
| R6 | 规则化身 | 自身即规则的延伸 |
| R7 | 改写一域 | 能改动一方天地的规则 |
| R8 | 半规则 | 人已不完全是"人" |
| R9 | 规则本身 | 成为律海的一部分，几乎不可交流 |

### 5.2 客道七境与位阶

| 客道 | 位阶 | 能力 | 客栈阶 |
|---|---|---|---|
| 迎客 | R1 | 感知客人真实需求 | 破店 |
| 奉茶 | R2 | 以"礼"稳定十步内规则 | 小院 |
| 掌勺 | R3 | 以"食"调和异种规则 | 楼 |

**双轨的真正含义**：个人修到 R7 就到顶了；**要到 R9，必须靠"界"——也就是组织、人口、制度、文明。**
这是全书"建设不能省"的物理保证：一个人永远成不了 R9。

## 6. 代价与限制

### 6.1 律价表（越阶使用的后果）

| 越阶 | 代价 |
|---|---|
| 越 1 阶 | 短期虚弱、律蚀入体 |
| 越 2 阶 | 永久损伤（断一肢、失一感、少十年寿） |
| 越 3 阶 | 半规则化，人格开始崩 |
| 越 4 阶以上 | 成为律祟/畸物/住户，等同死亡 |

**没有"燃烧寿命开大招"以外的便宜路子**，且燃烧也有上限。

### 6.2 为什么强者不能随便破店规

店规不是"法律"，是**局部规则垄断**：

- 店内规则密度由店规独占，外来规则被压制到 R0。
- 强者要破规，等于用自己的规则去撞一整套"已成域"的规则。
- 代价公式：**破规代价 ≈ 店的规则位阶 × 店的客流（人气即规则强度）**。

所以一个 R7 的域主硬闯一家"城"级客栈，可能付掉半条命——**这就是"每个强者都要吃一次瘪"的物理依据**。

### 6.3 店规的边界

| 能管 | 不能管 |
|---|---|
| 店内的人、行为、言语 | 店外的追杀 |
| 店内的规则冲突 | 天劫、兽潮等"自然规则" |
| 客人与客人的纠纷 | 客人自己带来的因果 |
| 门的通行权 | 门另一头的世界 |

**店规能压人，压不住天。** 这条边界要一直守住。

## 7. 战斗规则

### 7.1 胜负三要素

```
位阶差 × 规则兼容 × 环境密度
```

- **位阶差**决定"能不能伤到"。
- **兼容**决定"能不能借力"。
- **密度**决定"力量还剩几成"。

**三者相乘，不是相加。** 一项为零，结果就是零——所以 R6 的修士在灰原会被一个 R0 的枪手打死。

### 7.2 战斗不是数值，是"解释权"

高手过招，争的是**谁的解释生效**：
- 修士说"我说有剑，就有剑"；
- 工程师说"你的剑不符合应力结构"；
- 教徒说"你的剑为神所禁"；
- 店规说"店内不得动武"。

**谁的解释被环境接受，谁就赢。** 这是全书战斗的写法，也是"规则怪谈"能压修仙的原因。

### 7.3 战斗占比

- 全书战斗 < 30%
- 每场战斗必须服务一次经营决策
- 不做无赌注的比武

## 8. 特殊存在

| 存在 | 成因 | 位阶 | 特征 |
|---|---|---|---|
| **律祟** | 规则失控后诞生 | R3–R7 | 有规则、无自我 |
| **畸物** | 畸变走到尽头 | R4–R8 | 有力量、无人格 |
| **住户** | 在无言乡入册 | 不明 | 不死、不老、不能离开 |
| **半规则生物** | 律蚀重症 | R2–R5 | 身体部分变成规则 |
| **规则化身** | R6+ 的强者 | R6–R7 | 自身即规则，弱点是规则本身 |
| **祖巫** | 洪荒原生残片 | R8–R9 | 已不能算人 |
| **无名之物** | 律海渊的存在 | R9 | 无法交流，只能遵守 |

## 9. 留白：四个不能急着回答的问题

1. **律海为何破碎？** —— 留到第三幕。
2. **规则能否被真正创造？** —— 客栈的"内界"可能是唯一例外，也是终局钥匙。
3. **客道为何能立规？** —— 与万象簿同源，第二幕揭一半。
4. **R9 之后是什么？** —— 不写。留白比答案值钱。

## 10. 写作检查表

写任何一场力量相关的情节，过这五问：

1. 载体是什么？
2. 形式是什么？
3. 谁有权限？
4. 付了什么代价？
5. 当前环境的规则密度是多少？

五问答不全，这场戏就是"设定漏气"。
