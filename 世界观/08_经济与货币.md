# 经济与货币

> 版本：v0.1
> 定位：给客栈一本能算的账。世界可以荒诞，钱、粮、人、物流四本账必须自洽。
> 一句话：**没有统一货币，只有不断换汇的八个市场；客栈赚的是差价、服务与信息，不是印钱。**

---

## 0. 五条铁律

1. **没有世界统一货币。** 每种钱都有发行者、锚定物和流通范围。
2. **跨境必须换汇。** 换汇有手续费、有价差、有管制，也有黑市。
3. **物价由物流决定。** 同一件货，在产地和异域的价格差，主要来自运费、风险与税。
4. **系统不印钱。** 万象簿只给图纸、账本与验收标准，不给资本。
5. **客栈的利润有上限。** 住宿、餐饮、换汇、仓储、保险、信息服务，每一项都薄；靠复购与网络，不靠暴利。

## 1. 世界层：宝与会票

### 1.1 宝：不是硬币，是记账单位

八域货币互不承认，跨域贸易需要一个共同尺度。万宝楼在 1850 年推出**宝**，作为会票结算的记账单位：

- **1 宝** ≈ 云篆洲丰年 1 石粗粮（约 120 斤）的批发价。
- **1 宝 = 100 分**，只用于记账，不铸币。
- 宝没有实体，不能被伪造；能伪造的是会票与各地货币。
- 宝的购买力随粮价波动，万宝楼每月公布一次**宝价**。

**宝不是钱，是尺子。** 客栈可以用宝记账，但不能拿宝直接付账；必须换成当地货币。

### 1.2 万宝会票

万宝楼的跨域汇兑工具，本质是"凭票提货"：

| 项目 | 规则 |
|---|---|
| 起汇 | 100 宝 |
| 手续费 | 3%（客栈可谈到 2.5%） |
| 结算 | 7 日 |
| 覆盖 | 云篆洲、铁枢、蒸枢、辉庭、畸城、灰原 |
| 不覆盖 | 太荒（无正式金融）、无言乡（只认香火与纸钱） |
| 抵押 | 仓库现货、商队货单、庄园地契 |
| 风险 | 伪造、挤兑、战乱、律蚀断链 |

**会票的信用来自货，不来自楼。** 万宝楼若没有货，会票就是纸。

### 1.4 换汇的三层价差

| 层 | 价差 | 谁赚 |
|---|---|---|
| 官方牌价 | 0 | 发行者 |
| 钱庄/钱会 | 2–5% | 换汇商 |
| 黑市 | 10–30% | 走私者、帮派 |
| 客栈 | 3%（小额） | 客栈；大额仍走万宝楼 |

客栈的换汇优势：**小额、即时、不问来历**；劣势：资本薄，遇到大额会票吃不下。

## 2. 八域货币与日常购买力

### 2.1 云篆洲：灵石本位，灵票为辅

| 层级 | 形态 | 谁用 | 购买力 |
|---|---|---|---|
| 高阶灵石 | 灵脉结晶 | 元婴以上、大宗交易 | 1 枚 = 1,000 宝 |
| 中阶灵石 | 切割灵晶 | 金丹、宗门采购 | 1 枚 = 100 宝 |
| 低阶灵石 | 碎灵 | 外门弟子、散修 | 1 枚 = 10 宝 |
| 灵票 | 宗门/仙朝纸票 | 坊市、跨洲汇兑 | 1 两面值 ≈ 1 宝 |
| 银锭/铜钱 | 金属币 | 凡人、低阶修士 | 1 两 = 1 宝 |

- **灵票的风险**：小宗门超发，票面打折；青冥宗的票最硬，天衡仙朝的票最稳但手续繁。
- **灵脉枯竭**：3500 年后低阶灵石涨 30–50%，灵票跟着贬值。
- **凡人工资**：杂役 0.1 宝/日，匠人 0.2 宝/日，小吏 0.3 宝/日。

### 2.2 太荒：没有钱，只有货

- **兽核**：低阶 5 宝，中阶 50 宝，高阶 500 宝；祖巫遗族的骨币不流通。
- **盐、铁、皮、骨**：按斤/张计价；盐是最硬的硬通货。
- **血契**：部落间的信用，以人质、猎场、贡礼作抵押；外域不认。
- **交换**：一支猎团用 3 张兽皮换 1 把铁刀；客栈若收太荒客，最好收兽核与盐，不收"承诺"。

### 2.3 铁枢：信用点，钱即权限

- **信用点**：与信用分绑定；A 级可透支，D 级连租房都难。
- **企业券**：三大公司发行，只能在自家生态用；折价 0.5–0.8 宝。
- **断网**：信用点瞬间失效；底城因此流行以物易物。
- **手续**：跨境支付要过审计院，手续费 2%，审查 0.1 宝/单。
- **凡人工资**：底城 0.05 宝/日，外环 0.15 宝/日，墨心 0.4 宝/日。

### 2.4 蒸枢：工时券与锅炉票

- **工时券**：1 张 = 8 小时标准工时 = 0.8 宝；罢工时券会打折。
- **锅炉票**：1 张 = 100 斤标准煤 = 2 宝；冬季涨到 2.4–3 宝。
- **厂主券**：私厂发的代金券，出了厂门就没人认；风险极高。
- **工资**：炉工 0.12 宝/日，技师 0.25 宝/日，工头 0.4 宝/日。
- **煤荒**：蒸枢最怕的不是没钱，是没煤；煤价一涨，全城物价跟着涨。

### 2.5 辉庭：冠币、什一税与赦罪券

- **金冠/银冠/铜冠**：1 金冠 = 20 银冠 = 240 铜冠；1 银冠 ≈ 1 宝。
- **什一税**：收成的 10%，以粮、酒、银缴纳；抗税会被绝罚。
- **赦罪券**：不是货币，是"罪的期货"；按罪档 0.5–20 宝，黑市可炒。
- **朝圣税**：1 宝/人；朝圣道上的客栈因此有稳定客流。
- **工资**：农奴无现金，自由农 0.08 宝/日，工匠 0.2 宝/日，骑士 0.5 宝/日。

### 2.6 畸城：白蜡券、抑制剂与旧币

- **白蜡券**：白蜡财团发行，1 券 = 0.7 宝；只能买指定商品，黑市 0.5 宝。
- **抑制剂**：普通 2 宝/支（3 天），强效 8 宝/支（7 天）；断药即畸变失控。
- **旧币**：旧世界纸币/硬币，收藏与黑市用，0.1–0.2 宝。
- **工资**：下层 0.05 宝/日，帮派打手 0.2 宝/日，白蜡职员 0.4 宝/日。
- **债务**：畸城最普遍的不是税，是药债；很多人给财团打一辈子工。

### 2.7 无言乡：香火、纸人、替身与寿

- **香火**：1 炷 = 0.3 宝；在雾内是硬通货，出雾即失效。
- **纸人**：1 个 = 2 宝；跑腿、替灾、代跪。
- **替身**：1 个 = 50 宝；需守则局登记，替一次大劫。
- **年寿**：黑市 300 宝/年；违法，且"买的寿"会带因果。
- **规矩经济**：这里不按供需定价，按"条文"定价；讲价本身可能违规。

### 2.8 灰原：铁路券、弹药与水

- **铁路券**：横贯铁路公司发行，1 券 = 0.9 宝；公司破产即废纸。
- **弹药**：1 发步枪弹 = 0.5 宝；赏金客的"零钱"。
- **水**：20 升 = 0.4 宝；旱季 0.8 宝；水站是真正的权力。
- **盐**：1 斤 = 0.8 宝；内陆 1.1 宝。
- **工资**：铁路工 0.08 宝/日，赏金客一单 5–20 宝，镇长月薪 3 宝。

## 4. 商路、运费与跑商

### 4.1 运费基准（每 100 里/每斤）

| 方式 | 运费（宝） | 速度 | 风险 |
|---|---|---|---|
| 马车/步行 | 0.02 | 50–80 里/日 | 劫匪、兽群 |
| 驿道马车 | 0.025 | 100 里/日 | 关卡抽税 |
| 铁路 | 0.01 | 300 里/日 | 断轨、劫车 |
| 飞空艇 | 0.08 | 600 里/日 | 风暴、失事 |
| 地下管道 | 0.015 | 250 里/日 | 塌方、管费 |
| 海路 | 0.008 | 300 里/日 | 海盗、海雾 |

**运费公式**：

```
运费 = 基准 × 距离（百里） × 重量（斤） × 风险系数
风险系数：安全 1.0；一般 1.2；危险 1.5–2.0；战时 3.0
```

### 4.2 三条跑商模板

**① 灵药：云篆洲 → 灰原**

| 项 | 数值 |
|---|---|
| 进货 | 清心草 1 斤 = 2 宝 |
| 运费 | 4 日陆路 ≈ 0.3 宝/斤 |
| 税费 | 关卡 0.2 宝/斤 |
| 风险 | 10% 损耗 |
| 到岸成本 | 2.5 宝/斤 |
| 灰原售价 | 4.5 宝/斤 |
| 毛利 | 2.0 宝/斤（44%） |

**② 废铁：灰原 → 铁枢**

| 项 | 数值 |
|---|---|
| 进货 | 0.05 宝/斤 |
| 运费 | 2 日铁路 ≈ 0.02 宝/斤 |
| 税费 | 0.01 宝/斤 |
| 到岸成本 | 0.08 宝/斤 |
| 铁枢售价 | 0.12 宝/斤 |

**③ 煤：蒸枢 → 云篆洲**

| 项 | 数值 |
|---|---|

## 6. 金融：钱庄、当铺、保险与信用

### 6.1 谁在放贷

| 机构 | 利率 | 抵押 | 风险 |
|---|---|---|---|
| 万宝楼 | 5%/月 | 货单、地契、会票 | 挤兑、伪造 |
| 云篆洲钱庄 | 3%/月 | 灵石、灵田、法器 | 灵脉枯竭 |
| 铁枢银行 | 1.5%/月 | 信用分、义体、数据 | 断网、信用降级 |
| 蒸枢工会信用社 | 4%/月 | 工时券、锅炉票 | 罢工、炸炉 |
| 辉庭圣廷钱庄 | 2%/月 | 圣物、地产、什一税 | 教规、绝罚 |
| 畸城帮派钱庄 | 15%/月 | 抑制剂、器官、人 | 暴力催收 |
| 灰原铁路公司 | 8%/月 | 铁路券、车皮、矿权 | 断轨、劫车 |
| 太荒/无言乡 | 无正式金融 | 血契/香火契 | 无法强制执行 |

### 6.2 保险

- **货运险**：万宝楼，保费 5–15%，按货值；战乱/律蚀不保。
- **住客险**：客栈可卖，0.1 宝/晚，保"店内失窃/店规范围内受伤"；不保店外追杀。
- **开业劫**：没有保险公司接；这是客栈自己的风险。
- **客栈的保险生意**：与万宝楼合作，抽 20% 佣金；赔付由万宝楼出，客栈只做前端。

### 6.3 信用

- **铁枢信用分**：A/B/C/D；跨境不认，但万宝楼参考。
- **客栈信用**：常客可赊 2 宝，30 日免息；坏账率 5%，所以赊账额度小。
- **客票**：客栈可发"客票"（预付/储值），但只在店内流通；不能当货币。
- **会票**：大额走万宝楼，客栈只做中介，不自己做庄。

## 7. 通胀、危机与传导

### 7.1 常见冲击

| 冲击 | 影响 | 传导 |
|---|---|---|
| 律海退潮 | 灵药 +30–50% | 云篆洲减少进口煤 → 蒸枢煤价波动 |
| 煤荒 | 煤 +80% | 蒸枢全城物价上涨 → 灰原铁路运费上涨 |
| 兽潮 | 兽核 -30%，兽材 +50% | 太荒贡礼加重 → 边境盐价上涨 |
| 铁路垄断 | 运费 +20% | 灰原水/盐上涨 → 七镇联盟抗议 |
| 抑制剂断供 | 药价 +200% | 畸城黑市繁荣 → 灰原药价跟涨 |
| 赦罪券泡沫 | 券价 +300% | 辉庭教权危机 → 朝圣客流下降 |
| 香火短缺 | 香火 +100% | 无言乡条文收紧 → 住户外逃 |
| 信用分黑客 | 信用点 -20% | 铁枢底城挤兑 → 企业券折价 |

### 7.2 一条完整的危机链（示例）

```
律海退潮
→ 云篆洲灵药减产、灵石涨价
→ 云篆洲减少向蒸枢买煤
→ 蒸枢煤价先跌后涨（冬季）
→ 灰原铁路运力紧张、运费涨
→ 灰原水/盐涨
→ 客栈进货成本涨
→ 客栈要么涨价（得罪客），要么减量（得罪供应商）
```

**这条链就是第一幕之后的经济背景。** 主角不能阻止枯潮，只能提前囤货、换供应商、改菜单、签长期合同。

### 7.3 通胀下的客栈对策

1. **提前锁价**：与供应商签 3 个月固定价，付 10% 定金。
2. **替代菜单**：灵茶涨了就上"灵茶兑粗茶"，价格不变，成本降。
3. **跨域采购**：云篆洲灵药贵，就从灰原黑市补；风险高，但便宜。
4. **会员预付**：让客人预付 10 宝，锁 3% 折扣；拿到现金流。
5. **仓储套利**：淡季囤盐/煤/药，旺季卖出；占本金，但客栈有仓。
6. **不赌单一货币**：收灵石、银冠、铁路券，分散风险；每天按宝价重估。

## 9. 写作检查表

写任何一笔钱、一次买卖、一次涨价，过这五问：

1. **谁发行？** 这种钱谁认，谁不认？
2. **抵押是什么？** 货、地、信用、命，还是空口？
3. **汇率多少？** 官方价、黑市价、客栈价，差在哪？
4. **运费与税多少？** 这笔买卖的真实成本是多少？
5. **谁抽税/保护费？** 赚的钱最后进谁口袋？

五问答不全，这笔账就是假的。
