# 暗面组织：暗账

> 版本：v0.1
> 定位：幕后流的执行机构。东家不站台前，但必须有人替他下场。
> 一句话：**明账记客，暗账记债；客栈养人，暗账用人。**

---

## 0. 五条铁律

1. **东家不认。** 三层否认：对外，东家不知情；对内，掌灯人全权；对下，每人只知道自己的那一格。
2. **店规优先。** 店内不动武、不抓人、不杀客。所有暗活发生在"门外三步"。目标若是住店客人，先送客，再动手。
3. **每单有价。** 没有免费的任务。佣金、封口费、抚恤金都走账，暗账必须自养。
4. **先谈后杀。** 升级阶梯：谈 → 买 → 吓 → 抓 → 关 → 杀。跳级要有人签字，签字的人负责。
5. **它让谁留下来了？** 暗面不是独立的黑暗线。每个任务都要为一个人提供位置，或为客栈换来一道护城河；答不上来，不接。

## 1. 组织总览

### 1.1 名字与符号

| 项 | 内容 |
|---|---|
| 内部正式名 | **暗账** |
| 对外说法 | 客栈的"夜班""仓房""跑外单的" |
| 西文代号 | **Off-Books**（只用于辉庭、铁枢的合同） |
| 格言 | **灯下最黑，账外最真。** |
| 符号 | 一盏灯，灯下压着一本没有封面的账册 |

**为什么叫"暗账"**：客栈有一本明账，记客人、记流水、记欠款；暗账记的是明账不能写的事。它不是另一个组织，是客栈的第二本账。

### 1.2 层级

```
写账人（东家，唯一不具名）
  └ 掌灯人（唯一知道全貌的人）
      ├ 永恒 / Eternity —— 主事
      ├ 轮回 / Samsara —— 主事
      └ 深渊 / Abyss —— 主事
            └ 组长 → 伙计 / 线人
```

| 层 | 谁 | 知道什么 | 能做什么 |
|---|---|---|---|
| **写账人** | 主角 | 全部 | 定价、划"不可碰"、批跳级 |
| **掌灯人** | 一人 | 全部名单与账目 | 日常总指挥、对外承接 |
| **主事** | 三人 | 自己那一部的完整名单 | 立项、执行、向掌灯人负责 |
| **组长** | 若干 | 自己那一组 | 带队、现场决断 |
| **伙计/线人** | 最多 | 自己那一单 | 只做被交代的事 |

- **写账人只有掌灯人知道是谁。** 三个主事都以为自己是在为"掌灯人"做事；掌灯人以为自己在为"东家"做事；只有东家知道，这两句话是同一个人。
- **掌灯人首选裴昭**（大掌柜：管人、管契约、管对外），**备选苏九**（账房：管账、管档案、管证据）。掌灯人只能有一个，另一个做"副灯"，互相制衡。
- **裴昭的悖论**：她的独立目标是"证明制度可以不带血"，而掌灯人偏偏要管一本沾血的账。她越想把暗账做成制度，越要面对"制度也会杀人"——这是她人物弧光的核心。
- **没有专职杀手。** 所有人白天都有岗位，晚上才有任务。这是暗账与一般刺客组织的根本区别。

### 1.3 规模与扩张

| 阶段 | 人数 | 结构 | 对应客栈阶 |
|---|---|---|---|
| 破店 | 3–5 | 掌灯人 + 每部 1 人 | 破店 / 小院 |
| 小院 | 9 | 三部 × 三组 | 小院 / 楼 |
| 楼·坊 | 30 | 每组 3–5 人 | 楼 / 坊 |
| 城 | 100+ | 增设"外站" | 城 / 洞天 |

**扩张规则**：

1. 先满编，再增部。
2. 新增一部，必须走"注册 → 评估 → 试点 → 正式登记"流程（与《01_世界观注册表》同构）。
3. 每卷最多新增一个组，不新增部。
4. 新增部的名字不能与既有世界观概念撞车（见 §5 的"深渊"说明）。

## 2. 三部与六类任务

### 2.1 总表

| 任务 | 归属 | 科室 | 一句话 |
|---|---|---|---|
| 搜集情报 | **永恒** | 档案科 | 把发生过的，留下第二份 |
| 反渗透 | **永恒** | 镜厅 | 先查自己人 |
| 抓捕 | **轮回** | 缉拿组 | 活捉优先 |
| 关押 | **轮回** | 寄押所 | 关人，也关身份 |
| 暗杀 | **深渊** | 无归 | 只杀规则杀不了的人 |
| 交涉谈判 | **深渊** | 黑室 | 谈得成是生意，谈不成是事故 |

**派生任务**（渗透、绑架、勒索、洗钱、伪造、走私、保护、押运）不单设部门，按性质归口：

- 需要"长期看住一个人"→ 永恒；
- 需要"把人带走/留住"→ 轮回；
- 需要"让一件事永远不发生"→ 深渊。

### 2.2 为什么谈判归深渊

因为谈判是**不可逆动作之前的最后一道门**。

- 黑室先谈，无归兜底；谈得成，不需要杀；谈不成，才轮到无归。
- **深渊的 KPI 不是杀人，是"不用杀"。** 一个季度里，黑室谈成的单子越多，深渊的考核越好。
- 这也防止组织变成"遇事就杀"的刺客公会——**能谈的，绝不杀；能买的，绝不抓。**

### 2.3 任务升级阶梯

| 级 | 动作 | 谁执行 | 代价 | 适用 |
|---|---|---|---|---|
| 0 | **谈** | 黑室 | 时间、面子 | 一切冲突的首选 |
| 1 | **买** | 黑室 / 永恒 | 钱、把柄 | 对方要价合理 |
| 2 | **吓** | 永恒 / 黑室 | 暴露意图 | 对方怕失去 |
| 3 | **抓** | 轮回 | 人手、押送风险 | 需要活口 |
| 4 | **关** | 轮回 | 长期成本、替身 | 需要时间 |
| 5 | **杀** | 深渊 | 店规裂缝、因果 | 前四级全失败 |

**跳级规则**：

1. 必须掌灯人签字，写明"为什么不能停在前一级"。
2. 签字后，执行人终身不得升任掌灯人。
3. 跳级三次以上的人，自动进入"镜厅"的观察名单。

**写作用法**：每场冲突先问"现在在第几级"，不要一上来就杀。**级数越低，越像主角的手笔；级数越高，越像失控。**

## 3. 永恒 / Eternity

> 内部绰号：**档房**
> 格言：**"凡发生过的，都有第二份。"**

### 3.1 职责与科室

| 科室 | 职责 | 手段 |
|---|---|---|
| **档案科** | 客簿、账本、口供、剪报、地图、人物卡 | 记录、抄本、交叉验证、分三份保管 |
| **镜厅** | 反渗透、双面间谍、内部审查 | 查"自己人有没有被换过"、茶水试伪装 |
| **线网** | 线人、跑堂、说书人、商队、码头 | 只管广度，不管深度 |

### 3.2 工作流

```
收 → 验 → 存 → 用 → 销
```

- **收**：至少两条独立来源，否则标"孤证"。
- **验**：能用第三方验证的，绝不用自己人验证。
- **存**：一份在档房，一份在掌灯人，一份在"看不见的地方"。
- **用**：只用手上最旧的那份，不用最新那份——最新那份往往是对手放的。
- **销**：用完的情报不销毁，标"过期"，因为过期情报能看出对手的布局节奏。

### 3.3 资产与代价

- **资产**：客簿、万象簿的"客源"模块、各域驿站、说书人的嘴、灵植的"耳朵"。
- **代价**：知道太多的人不能退休；档案员记不住自己的事，只记得别人的事。
- **禁忌**：**客人在店内说的话，不能当暗账的证据。** 用了，就是破店规第四条。这条禁忌让永恒必须用"观察"和"外围"补足，而不是靠偷听。

### 3.4 失败模式

1. 孤证当真，杀错人。
2. 反渗透过度，自己人先互相怀疑。
3. 档案被篡改，历史被改写。
4. 线人被反向收买，喂回来的全是真话——真话最贵，也最致命。

### 3.5 人物接口

- **苏九**（账房）：暗账与档案科；掌灯人备选。
- **薇拉**（说书人）：线网与舆论；她管"别人愿意相信什么"。
- **青萝**（花匠）：灵植为耳；植物不会说谎，但会记错。

### 3.6 单元剧种子

1. 客簿上多了一个不存在的客人，笔迹是苏九自己的。
2. 镜厅抓到一个内鬼，审到最后发现他是三年前派出去的自己人。
3. 一份孤证指向客栈自己。

## 4. 轮回 / Samsara

> 内部绰号：**仓房**
> 格言：**"人不是消失了，是换了个名字。"**

### 4.1 职责与科室

| 科室 | 职责 | 手段 |
|---|---|---|
| **缉拿组** | 活捉、追逃、押送 | 先用规矩逼人自投，再动手 |
| **寄押所** | 关押、审讯、身份置换、替身管理 | 不在客栈内界；另设"驿外寄押点"（独立锚点） |
| **渡口** | 押送、交接、跨境转移 | 分店的门、畸城暗管、灰原铁路、无言乡的门 |

### 4.2 工作流

```
确认身份 → 封门 → 活捉 → 寄押 → 置换 / 释放 → 销案
```

- **活捉优先**：死人不会说话，也换不到钱。
- **封门**：先封住对方的"退路"（身份、钱、路），再封物理的门。
- **寄押**：关押点不在客栈内界，另设"驿外寄押点"，避免店规第一条。"仓房"只是轮回的内部绰号，不是客栈的仓房。
- **置换**：能换身份就不关人；能放人就不杀。
- **销案**：案卷进档房，人进"轮回"——从此世上少一个名字，多一个替身。

### 4.3 资产与代价

- **资产**：无言乡的替身与门牌、畸城的暗管、灰原的铁路、客栈的分店门。
- **代价**：抓错人无法挽回；关久了，人会变成另一个人；每次"轮回"都要有人顶替那个身份。
- **禁忌**：**不抓店里的客人。** 客人要走，先让他走；出了门，才是目标。用店规第二条"欠账者不得离店"留人，可以，但只能留到账清，不能留到事成。

### 4.4 失败模式

1. 替身反噬，顶替者不肯交还身份。
2. 押送被劫，人和案卷一起丢。
3. 关押者变成"住户"——没死，但已经不在名册上。
4. 抓了不该抓的人，对方的背景比客栈硬。

### 4.5 人物接口

- **阿宁**（守门人）：渡口与替身；她本来就在"住户"名册上。
- **阿雀**（跑堂）：缉拿与地头；她认识所有不该认识的人。
- **苏医生**（医师）：寄押所医官；她负责让被抓的人活着。

### 4.6 单元剧种子

1. 抓回来的人说："我三年前就被你们抓过一次。"
2. 替身不肯交还身份，因为她爱上了被顶替者的生活。
3. 寄押所里关着一个名册上不存在的人。

## 5. 深渊 / Abyss

> 内部绰号：**暗窖**
> 格言：**"先谈。谈不拢，再谈一次。"**

### 5.1 命名说明（重要）

本文件里的"深渊"，是暗账第三部的代号；它与无言乡的"**深渊型**"怪谈（律海渊、不可名状）**不是一回事**。

- 暗账故意借用了这个最吓人的词，作为对外代号；对内只叫"暗窖"。
- 正文第一次出现时，必须让角色误会一次：听见"深渊的人来找你"，先想到怪谈，再发现是客栈。
- 这个误会是设定内的笑点，也是恐点：**世界上最像怪谈的东西，有时只是一本账。**

### 5.2 职责与科室

| 科室 | 职责 | 手段 |
|---|---|---|
| **黑室** | 谈判、交易、威胁、赎金、人质交换、停战 | 先谈后杀；用价码代替威胁 |
| **无归** | 暗杀、抹除、伪造意外 | 只接"规则杀不了的人" |
| **沉档** | 收尾、销毁证据、编造死因、安抚家属 | 不留名、不留尸、不留因果 |

### 5.3 工作流

```
接单 → 定价 → 谈 → 吓 → 杀 → 沉档
```

- **接单**：先问"这人为什么非死不可"；答不上来，转黑室。
- **定价**：价格必须高到让对方认真考虑"不杀"；低价暗杀会养出滥杀。
- **谈**：黑室先出三次价，每次都留对方一条退路。
- **杀**：只杀"规则杀不了的人"——法律、教会、宗门、帮派都动不了的那种。
- **沉档**：死因、目击者、家属、赔偿，四件事一起收。

### 5.4 资产与代价

- **资产**：暗窖（谈判室与临时关押点）、真话酒、宴席、各域的"脏活"渠道。
- **代价**：每动一次手，店规就裂一道缝；杀手不能住在店里；谈判失败要有人负责。
- **禁忌**：**不杀店里的客人，不杀伙计，不杀供货商。** 这三条是"不可碰清单"的底线。

### 5.5 失败模式

1. 杀错人——暗账最致命的错误，没有之一。
2. 谈判把对方逼成死敌，本来能买，最后只能杀。
3. 店规反噬：在店内动了一次手，店规对主角也裂了一道缝。
4. 沉档没沉干净，死者"回来"住店。

### 5.6 人物接口

- **沈青梧**（护院）：无归；她只杀该杀的人，也只破该破的誓。
- **裴昭**（大掌柜）：黑室；她最会把"威胁"说成"合作"。
- **黛安**（酿酒师）：真话酒；谈判桌上的第二把刀。
- **阿禾**（大厨）：宴席谈判；很多事在饭桌上谈成，比在黑室谈成便宜。

### 5.7 单元剧种子

1. 黑室谈成一单，对方付的钱正好是客栈下个月的房租。
2. 无归接到一单，目标是店里住过的客人——必须先"送客"。
3. 被暗杀的人没死，回来住店，坐在凶手对面吃饭。

## 6. 接单与执行：七步 SOP

| 步 | 动作 | 产出 | 谁签 |
|---|---|---|---|
| 1 | **接单**：客户、目标、价钱、期限 | 任务单 | 掌灯人 |
| 2 | **立项**：归口、配合、封面故事、预算 | 立项单 | 主事 |
| 3 | **布点**：情报先行、路线、退路、替身 | 布点图 | 永恒主事 |
| 4 | **执行**：按阶梯升级，逐级留痕 | 执行记录 | 现场组长 |
| 5 | **收尾**：封口、证据、赔偿、安抚 | 收尾报告 | 深渊·沉档 |
| 6 | **归档**：什么留、什么烧、什么记进暗账 | 暗账条目 | 掌灯人 |
| 7 | **复盘**：是否护住店、是否让人留下 | 复盘页 | 写账人 |

**三张单子**：任务单（接不接）、立项单（怎么做）、收尾报告（擦没擦干净）。缺一张，单子作废，钱不退。

**不可碰清单**：

- 店里的客人、伙计、供货商、盟友；
- 掌灯人划掉的名字；
- 任何"杀了会引来域主级存在"的人。

碰了，按叛徒处理。**先问为什么，再动手；不问就杀，掌灯人失格。**

## 7. 暗账：钱、价目与抚恤

### 7.1 收入

- 佣金、情报费、谈判抽成、保护费、赎金、替身服务、押送费。
- 不收"空头人情"；人情要折成"欠条"，记在暗账上。
- 暗账不养闲人：每个组每月必须至少完成一单，否则缩编。

### 7.2 价目（示例，单位：宝）

| 服务 | 价格 | 备注 |
|---|---|---|
| 一条孤证 | 1–5 | 不保真 |
| 一条双源情报 | 10–30 | 可作证据 |
| 反渗透清洗 | 50–200 | 按人头 |
| 活捉 | 100–300 | 不含押送 |
| 关押（每月） | 30–80 | 含口粮与药 |
| 谈判（每单） | 抽成 5–15% | 谈成才收 |
| 暗杀 | 500–2,000 | 只接"规则杀不了的人" |
| 替身 | 50–80 | 与无言乡市价联动 |

### 7.3 成本

- 线人费、封口费、抚恤金、替身费、运费、贿赂、铁枢律师费、辉庭赦罪券。
- 净利：15–25%（扣除抚恤与封口后，常落到 10–20%）。暗账不是暴利生意，靠复购与网络。

### 7.4 抚恤与退休

| 情况 | 处理 |
|---|---|
| 死者 | 一次性抚恤 200 宝；代号进"灯下碑"，不写全名 |
| 伤者 | 转岗、配药、养老 |
| 退休 | 洗名、换脸、远调；不许留在客栈附近 |
| 叛徒 | 先问"为什么"，再按"不可碰"处理 |

### 7.5 与万象簿

- 万象簿知道暗账存在，但**不记**。它的说法是："账外之事，不在本簿。"
- 暗账是唯一一本万象簿拒绝审计的账。
- 主角多次要求系统开"暗账"模块，系统回答："本簿只记客，不记债。"
- 这是全书最重要的系统限制之一：**暗账必须人手记，所以会出错、会被偷、会反噬。**

## 8. 招募、训练与晋升

### 8.1 招募来源

- 住店客人里"无处可去"的人；
- 被救下的人、被除名的人、欠债的人、被通缉的人；
- 共同点：**有牵挂。** 没有牵挂的人不能用，因为无法约束。

### 8.2 三道测试

1. **一件脏活**：愿不愿意做，决定底线。
2. **一件善事**：做完不留名，决定心性。
3. **一件不能说的活**：对最亲近的人保密一个月，决定能不能进暗账。

### 8.3 训练

- 白天岗位训练 + 夜间技能训练。
- 跑堂学察言观色，账房学看假账，护院学擒拿，厨子学毒理（只学辨，不学下）。
- 每人都要会两样本事：**一样在台面上用，一样在台面下用。**

### 8.4 晋升

```
伙计 → 组长 → 主事 → 掌灯人
```

- 掌灯人只能由上一任指定，且必须经过"写账人"点头。
- 主事升掌灯人，必须先交出自己那一部的完整名单——**交出名单，就是交出退路。**

### 8.5 退出

- 正常退出：洗名、远调、给一笔钱。
- 非正常退出：替身、失踪、或者"轮回"。
- **退出的人不许再住店。** 这是店规与暗账之间最残忍的一条。

### 8.6 与后宫四阶段

| 阶段 | 她知道什么 | 她能做什么 | 她拿到什么 |
|---|---|---|---|
| 客 | 只知道有"夜班" | 无 | 安全感 |
| 伙计 | 知道暗账存在 | 外围配合 | 归属感 |
| 自己人 | 知道自己那一格 | 独立执行 | 平等 |
| 定契 | 知道掌灯人是谁 | 参与定价 / 否决 | 暗账股份 / 否决权 |

**暗账是后宫"职位制"的第二层**：白天是岗位，晚上是身份。她留下，不只是因为有工作，还因为她有了一个不能对别人说的位置。

## 9. 与客栈、店规、诸域的关系

### 9.1 店规边界

| 地点 | 能不能动手 | 原因 |
|---|---|---|
| 店内 | 不能 | 店规第一条 |
| 门槛 / 门外三步 | 不能（默认） | 店规的延伸解释；动手即破规 |
| 驿外寄押点 | 能（有限） | 不在客栈内界，是独立锚点 |
| 分店门内 | 不能 | 同店规 |
| 分店门外 | 能 | 与当地规则相同 |

- **"门外三步"是暗账最常用的灰色地带。** 主角的解释是："门槛以内是客，门槛以外是路。"
- 这句话会被各方反复挑战——宗门、教会、联邦、帮派，都想逼他承认"门外也是店内"。
- 一旦承认，暗账就失去活动空间；一旦否认得太硬，客栈的中立就没人信。

### 9.2 与八域的对口

|---|---|---|---|

| 太荒 | 九黎部 / 巫祝 | 只谈猎场与兽核 | 血脉同化 |
| 铁枢 | 审计院 / 棱镜 | 不伪造信用分 | 断网即瘫 |
| 蒸枢 | 锅炉总工会 | 不碰炉规 | 炸炉 |
| 辉庭 | 圣廷 / 灰袍修会 | 不碰神名与破誓者 | 异端审判 |
| 畸城 | 帮派 / 财团 | 不碰换药日 | 畸变失控 |
| 无言乡 | 守则局 / 城隍衙 | 不碰告示 | 条文吞噬 |
| 灰原 | 铁路公司 / 赏金行会 | 不碰路权 | 断轨、劫车 |

### 9.3 与客栈其他模块

| 后宫（05） | 暗账提供"夜间身份"，是"定契"的一部分 |

## 11. 十个故事钩子

1. **不存在的客人**：客簿多了一页，笔迹是苏九的，但她不记得写过。
2. **三次抓同一个人**：轮回抓了三次，每次抓回来的都是不同的人，名字却一样。
3. **杀手的房钱**：无归杀了人，回来第一件事是问"这单能不能走公账"。
4. **深渊来了**：客人听见"深渊的人"，以为是怪谈，吓得把店规从头读到尾。
5. **掌灯人是谁**：三个主事都以为自己是掌灯人，直到真正的掌灯人吹灭灯。
6. **暗账被偷**：偷账的人只偷了"抚恤"那一页，因为那页有他妹妹的名字。
7. **店规裂缝**：暗账在门外三步杀了人，店规第一次在店里"失灵"了一瞬。
8. **谈判对象是旧客**：黑室谈的价，正好是那位客人当年住店欠的房钱。
9. **系统拒审**：万象簿第一次开口说"这笔账，我不看"，主角知道它看见了什么。
10. **留客日**：暗账的退休名单和留客日的客人名单，第一次重合。

## 12. 写作检查表

写任何涉及暗账的情节，过这五问：

1. **这单在第几级？为什么不能停在前一级？**
2. **谁签的字？签字的人承担什么后果？**
3. **目标是不是店里的客人？如果是，怎么"先送客"？**
4. **这单的钱从哪来、到哪去？暗账这个月会不会亏？**
5. **这单让谁留下来了？如果答不上来，删掉。**

五问答不全，暗账就变成了"主角无所不能"的作弊器。
