# 暗面组织：暗账与九卷

> 版本：v0.2
> 定位：幕后流的执行机构。**优先服务主角与客栈，其次才对特定客户开放。**
> 一句话：**明账待客，暗账收债；灯照九卷，卷卷不认。**

---

## 0. 六条铁律

1. **主角优先，不对外营业。** 第一服务对象是灯主与客栈；第二服务对象是灯主批准的特定客户。没有公开价目，不接上门单，不接竞标单。
2. **东家不认。** 对外，东家不知情；对内，掌灯人全权；对下，每人只知道自己的那一卷。灯主一旦亲自下场，这一单就算坏账。
3. **店规优先。** 店内不动武、不抓人、不杀客。所有暗活发生在"门外三步"。目标若是住店客人，先送客，再动手。
4. **卷不相认。** 九卷互不横向联系，只对掌灯人负责。一卷失手，最多暴露自己那一卷，牵不出其余八卷。
5. **先谈后杀。** 升级阶梯：谈 → 买 → 吓 → 抓 → 关 → 杀。跳级要灯主签字，签字的人负责。
6. **它让谁留下来了？** 每一单都要为一个人提供位置，或为客栈换来一道护城河。答不上来，不接。

## 1. 组织总览

### 1.1 名字、符号与来历

| 项 | 内容 |
|---|---|
| 内部正式名 | **暗账** |
| 对外说法 | 客栈的"夜班""仓房""跑外单的" |
| 西文代号 | **Off-Books**（只用于辉庭、铁枢的合同） |
| 次级组织统称 | **九卷** |
| 人员层级 | **灯主 → 掌灯人 → 副灯 → 卷灯 → 灯芯 → 灯影** |
| 格言 | **明账待客，暗账收债；灯照九卷，卷卷不认。** |
| 符号 | 一盏灯，灯下摊着一卷没有封面的账册；三卷有字，六卷空白 |

**为什么叫"暗账"**：客栈有一本明账，记客人、记流水、记欠款；暗账记的是明账不能写的事。它不是另一个组织，是客栈的第二本账。

**为什么是"九卷"**：暗账不是一叠散页，而是九卷可以摊开、合上、封存的账。卷是账的单位，也是事的单位：一卷管一类活，一卷有一盏灯。

**为什么人员用"灯"**：卷是写下来的，灯是照着做的。

> **卷是账，灯是人；卷无灯不亮，灯无卷不照。**

**来历**：万象簿在客栈升到"小院"时，解锁了一个从未亮过的模块——九卷空账。前三卷已经有名字：**永恒、轮回、深渊**；后六卷还是空白，只在卷脊上刻着用途。

**卷名不是作者起的，是第一次开卷时亮出来的。** 哪一卷第一次被真正使用，哪一卷的名字才会浮出来。所以：

- 已亮：永恒、轮回、深渊。
- 待亮：反渗透、暗杀、抓捕、谈判、舆论、资金六卷——**卷名与卷灯均未定，等后续剧情开卷时再定。**

> **长线悬念**：前三卷的名字是谁写的？后六卷为什么是空白？九卷全开之后，暗账会变成什么？

### 1.2 层级

```
灯主（主角，账上称"写账人"）
  └ 掌灯人（唯一知道灯主是谁的人）
      ├ 副灯（知道掌灯人，不知道灯主）
      └ 九位卷灯（各掌一卷，互相不认）
            └ 灯芯（组长）
                  └ 灯影（伙计 / 线人）
```

| 层 | 谁 | 知道什么 | 能做什么 |
|---|---|---|---|
| **灯主** | 主角 | 全部 | 开卷、封卷、定价、划"不可碰"、批跳级 |
| **掌灯人** | 待定（一人） | 全部名单与账目，以及灯主的身份 | 日常总指挥、对外承接、分配九卷 |
| **副灯** | 待定（一人） | 掌灯人与九位卷灯，但不知道灯主 | 财务复核、掌灯人缺席时接班 |
| **卷灯** | 九人，均待定 | 自己那一卷的完整名单 | 立项、执行、退单、向掌灯人负责 |
| **灯芯** | 若干 | 自己那一组 | 带队、现场决断 |
| **灯影** | 最多 | 自己那一单 | 只做被交代的事 |

**三条硬规则**：

1. **掌灯人只能有一个**，副灯是备份，不是分权。
2. **卷灯有退单权**：她可以拒绝一单，掌灯人不能强迫。强迫一次，卷印作废。
3. **没有人专职**。所有人白天都有岗位，晚上才有任务。这是暗账与刺客公会的根本区别。

> **人事留白**：本文件只定层级与职责，**不锁定任何具体人选**。掌灯人、副灯、九位卷灯，均由后续人物卷另行商定；未定之前，可由掌灯人代管。

### 1.3 服务对象：主角第一，客户第二

| 优先级 | 对象 | 谁批准 | 怎么算钱 | 说明 |
|---|---|---|---|---|
| 1 | **灯主 / 客栈** | 灯主 | 只记成本，不计佣金 | 第一优先；可以亏，但有限额 |
| 2 | **特定客户** | 灯主 + 掌灯人 | 按价目收费 | 白名单制，不公开、不宣传、不接上门 |
| 3 | **诸域势力** | 灯主 | 一事一议 | 只在"对客栈有利"时合作，不接长期雇佣 |

**特定客户白名单**（只列类型，不列名字）：

- 住过店、欠着店情的老客；
- 长期走同一条商路的伙伴；
- 被店规救过一次、愿意用一件事还情的人；
- 灯主亲自指定的人。

**三不接**：

1. 不接公开单——不在市面挂招牌，不参与竞价。
2. 不接竞标单——谁出价高就帮谁，暗账会变成别人的刀。
3. 不接与店规冲突的单——客户要动店内客，先送客，再谈。

**内外两账**：

- **内账**：主角与客栈的事，记成本、记人手、记风险，不记收入。
- **外账**：特定客户的事，记报价、记押金、记尾款。
- 两本账分开，但月底合并看一次：**暗账亏空不得超过明账净利的 15%。** 超过，封一卷或提价。

### 1.4 规模与扩张

| 客栈阶 | 卷数 | 人数 | 能接的任务 |
|---|---|---|---|
| 破店 | 0 | 1–3 | 只有"人情账"：传话、寻人、藏人 |
| 小院 | 3（永恒 / 轮回 / 深渊） | 9 | 情报、转移、关押 |
| 楼 | 6（+ 三卷待亮） | 30 | 加反渗透、抓捕、谈判 |
| 坊 | 9（+ 三卷待亮） | 60 | 加暗杀、舆论、洗钱 |
| 城 | 9 + 外站 | 150+ | 跨域行动 |
| 洞天 | 九卷成"九律" | 300+ | 规则级任务 |
| 界 | 明暗合一 | —— | 终局 |

**扩张规则**：

1. 先满编，再开卷。人不够，不接新类型的活。
2. 每卷最多开一卷；开卷必须由灯主签字。
3. 开卷时，卷名才会亮；未亮之前，只以功能编号称呼（第四卷、第五卷……）。
4. 任何一卷连续三个月亏损，自动降为"灯芯组"，并入相邻卷。

> **写作用法**：后六卷的名字可以一直空着。哪一卷第一次被用，哪一卷才亮名——**"开卷"本身就是一场戏**，也是作者给后续剧情留的自由度。

## 3. 九卷详解

> 每一卷都按同一套字段写：职责 / 不做什么 / 工作流 / 资产 / 失败模式 / 卷灯要求 / 单元剧种子。
> **卷灯要求**只写"需要什么样的人"，不写具体名字。

### 3.1 第一卷：永恒

> 内部绰号：**档房**。格言：**"凡发生过的，都有第二份。"**

**职责**：情报搜集、档案管理、身份核验、长期监视、失踪人口比对。

**不做什么**：不抓人、不杀人、不谈判；不把情报卖给账外的人；不碰客人的隐私（店规第四条）。

**工作流**：

```
收 → 验 → 存 → 用 → 销
```

- **收**：至少两条独立来源，否则标"孤证"。
- **验**：能用第三方验证的，绝不用自己人验证。
- **存**：一份在档房，一份在掌灯人，一份在"看不见的地方"。
- **用**：只用手上最旧的那份，不用最新那份——最新那份往往是对手喂的。
- **销**：过期情报不销毁，降级为"旧档"，留给下一单。

**资产**：客簿、三份副本、线网、旧档、各域方言与黑话。

**失败模式**：孤证、假情报、被对手喂料、线人反水。

**卷灯要求**：记忆力极好，能从三句闲话里听出一件事；能忍住不炫耀自己知道什么；最好在某个域做过"被人遗忘的人"。

**单元剧种子**：一份没有收货人的旧货单；同一个名字出现在三份互相矛盾的档案里。

---

### 3.2 第二卷：轮回

> 内部绰号：**渡房**。格言：**"带得走的人，才算救下。"**

**职责**：转移、救援、换身份、偷渡、人质交换、失踪者回收。

**不做什么**：不强行带走不愿走的人；不拆散家庭；不接"卖人"的单；不碰店内客。

**工作流**：

```
接人 → 换装 → 走线 → 交接 → 销名
```

- **接人**：先问"你是想走，还是想逃"；两者价钱不同。
- **换装**：衣服、口音、身份，三样一起换。
- **走线**：分店门、马车、暗管、铁路，四条线各有各的价。
- **交接**：交给客户、交给新身份、或交给"没有人的地方"。
- **销名**：旧名字进永恒档案，新名字进轮回名册。

**资产**：分店门、马车、暗管、假身份（永恒供）、灰原铁路（第九卷供）。

**失败模式**：路线断、被边检扣、救错人、被救的人自己回去。

**卷灯要求**：能让人相信"你还有另一条路"；最好自己走过一次；知道"在册"意味着什么，所以从不问被救的人"你以前叫什么"。

**单元剧种子**：一个不愿走的人；一次人质交换，发现双方都是受害者。

---

### 3.3 第三卷：深渊

> 内部绰号：**寄押所**。格言：**"进去的东西，不能比外面更自由。"**

**职责**：关押、收容、审讯、处理律蚀者、畸变者、规则失控者。

**不做什么**：不关无辜；不关客人；不刑讯逼供（只"问话"）；不关超过期限；不杀囚犯。

**工作流**：

```
收押 → 验身 → 分级 → 关押 → 处置
```

- **收押**：先问三件事：他会不会伤自己？会不会伤别人？会不会被外面的人灭口？
- **验身**：律蚀、畸变、条文污染，各有一套检查。
- **分级**：普通、危险、规则级。规则级关在铅墙里。
- **关押**：三日一查，七日一换房，防止"住熟了"。
- **处置**：释放、移交、治疗、或转给第五卷——最后一项必须灯主签字。

**资产**：静室、隔离间、铅墙、抑制剂、药圃。

**失败模式**：越狱、囚犯被"换走"、囚犯变成律祟、囚犯开始叫看守的名字。

**卷灯要求**：能面对"不该活的东西"而不先动手；要有医者的耐心，或狱卒的狠；必须相信"关是为了治，不是为了罚"。

**单元剧种子**：囚犯开始叫她的名字；一个囚犯是她十年前没救回来的病人。

---

### 3.4 第四卷（卷名待亮）：反渗透

> 功能代号：**内厅**。格言：**"先查自己人。"**

**职责**：反渗透、内部审查、身份复核、忠诚测试、泄密溯源。

**不做什么**：不参与外勤；不审客人；不替卷灯做决定；只出报告，不执行。

**工作流**：

```
疑 → 查 → 对 → 报 → 清
```

- **疑**：任何"来得太巧"的人、事、消息，先标疑。
- **查**：查旧档、钱路、口音、习惯。
- **对**：与永恒交叉验证，两边都确认才算实。
- **报**：报告只给掌灯人，不给卷灯。
- **清**：确认清白的人，要当面还他清白；这是这一卷的规矩。

**资产**：三重身份档案、茶水试伪装、旧审计工具、各域口音样本。

**失败模式**：误判、逼走好人、被反间、报告泄露。

**卷灯要求**：能审自己人，且不怕被恨；必须接受"查错了要当面认"；最好曾经被制度冤枉过一次。

**单元剧种子**：暗账里有一个"被换过"的人；这一卷查出掌灯人十年前的一桩旧案。

---

### 3.5 第五卷（卷名待亮）：暗杀

> 功能代号：**无归**。格言：**"一剑一账，无账不出剑。"**

**职责**：暗杀、清除、处理那些"审不了、关不住、谈不拢"的目标。

**不做什么**：不杀无辜；不杀店内客；不杀无账之人；不接私仇；不接灭门；不杀已经投降的人。

**工作流**：

```
立账 → 验罪 → 定级 → 出手 → 销痕
```

- **立账**：目标必须有至少一条"可上账"的罪：血债、规则债、毁约。
- **验罪**：永恒与第四卷双重确认，错一不可。
- **定级**：这是第 5 级动作，必须灯主签字。
- **出手**：一次只杀一个；不牵连。
- **销痕**：第八卷善后，第二卷撤人，第九卷结清尾款。

**资产**：剑、毒、假身份、撤退路线。

**失败模式**：目标错、目击者、因果反噬、杀完之后发现账是假的。

**卷灯要求**：能杀，也能拒绝杀；必须有自己的"剑誓"或等价物；每杀一人，要留下只有自己看得见的记号。

**单元剧种子**：目标是宗门误判的另一个受害者；这一卷第一次拒绝出剑。

---

### 3.6 第六卷（卷名待亮）：抓捕

> 功能代号：**缉房**。格言：**"能活捉，绝不杀。"**

**职责**：抓捕、押运、追逃、悬赏、保护。

**不做什么**：不杀（除非对方先动杀心）；不虐待；不抓未成年人；不抓店内客；不替人"教训"谁。

**工作流**：

```
接单 → 布控 → 活捉 → 押运 → 交人
```

- **接单**：客户要活口，或者要一个能上庭的证据。
- **布控**：永恒给位置，第九卷给钱路，这一卷布人。
- **活捉**：优先用网、锁、药，不用刀。
- **押运**：走第二卷的线，或走灰原铁路。
- **交人**：交给客户、交给深渊、或交给当地官府——三选一，必须写清楚。

**资产**：镣铐、囚车、赏金网络、畸城帮派关系。

**失败模式**：目标死了、押运被劫、抓错人、客户赖账。

**卷灯要求**：能活捉、能押运、能不虐；在灰色地带有人脉；最好自己被人抓过一次。

**单元剧种子**：一个"自愿被绑"的肉票；押运途中遇到兽潮，囚犯反过来救了她。

---

### 3.7 第七卷（卷名待亮）：谈判

> 功能代号：**前厅**。格言：**"先倒酒，再算账。"**

**职责**：谈判、赎金、换俘、停战、条约、黑市仲裁。

**不做什么**：不替人做决定；不签无法兑现的条约；不拿人质威胁；不接欺诈式谈判；不碰店内客。

**工作流**：

```
听 → 报价 → 试探 → 成交 → 见证
```

- **听**：先让对方说够，说到他漏出自己的底价。
- **报价**：一个价给客户，一个价给对方，中间的差额是暗账的佣金。
- **试探**：用一顿饭、一杯酒、一句闲话，试对方的底线。
- **成交**：口头成交不算，必须有一份能被第三域承认的文书。
- **见证**：找万宝楼、教会、或当地官府作见证；见证人也要付钱。

**资产**：雅间、酒窖、说书人、会票。

**失败模式**：谈崩、被扣押、条约被撕、双方都觉得自己亏了。

**卷灯要求**：能听、能等、能倒酒；能让双方都觉得自己赢了；必须守一条底线——酒可以让人说真话，不能逼人说真话。

**单元剧种子**：一场双方都想谈崩的谈判；一个肉票自己开价，价格比绑匪要的还高。

---

### 3.8 第八卷（卷名待亮）：舆论

> 功能代号：**说房**。格言：**"故事比刀快，但要比账慢。"**

**职责**：舆论、假消息、伪装、洗白、抹名、口碑运营。

**不做什么**：不造"害死人的谣"；不抹无辜者的名字；不冒充死者；不碰店内客；不替客户洗"洗不掉的血"。

**工作流**：

```
定调 → 放风 → 扩散 → 收口 → 销稿
```

- **定调**：一件事要被讲成什么故事？英雄、意外、天灾、还是"查无此事"？
- **放风**：先在小范围放，看谁先信、谁先传。
- **扩散**：说书人、商队、码头、酒馆，一层层往外推。
- **收口**：故事达到目的就停，不停就会自己长。
- **销稿**：原稿、底本、证人，三样都要处理；但"处理"不等于"杀"。

**资产**：说书台、话本、吟游公会、各域告示与报纸。

**失败模式**：故事失控、被教会查、被守则局"写进告示"、故事长出信徒。

**卷灯要求**：能讲故事，也能亲手杀掉自己的故事；心里必须有一个"不能被抹掉的名字"；否则这一卷会把人变成工具。

**单元剧种子**：一个假故事长出了信徒；她要抹掉自己恩人的名字。

---

### 3.9 第九卷（卷名待亮）：资金

> 功能代号：**账房**。格言：**"钱走过的路，都会留下水痕。"**

**职责**：资金、洗钱、贿赂、壳商号、跨境汇兑、佣金结算。

**不做什么**：不做高利贷；不碰客人的存款；不做人口买卖；不洗"血钱"（暗杀款单独走"白账"）；不替客户逃税到引发域战。

**工作流**：

```
收 → 拆 → 转 → 平 → 销
```

- **收**：佣金、封口费、服务费，三本账分开。
- **拆**：大额拆小额，跨域拆本地，会票拆现货。
- **转**：壳商号、铁路券、灵票、香火，四条通道轮换。
- **平**：每单结束必须平账；平不了的，记"坏账"。
- **销**：票据、底单、印鉴，三样分开销毁。

**资产**：换汇台、壳商号、万宝会票、铁路券。

**失败模式**：挤兑、假票、被审计院查、客户用脏钱引来追兵。

**卷灯要求**：能跟着钱走，又不被钱收买；必须记得第一笔账是从哪里来的；最好见过一笔"没有收货人的货"。

**单元剧种子**：暗账一半的资金来自万宝楼；一张会票连着三个域的死账。

## 4. 任务阶梯：先谈后杀

| 级 | 动作 | 谁执行 | 代价 | 适用 |
|---|---|---|---|---|
| 0 | **谈** | 第七卷 | 时间、面子 | 一切冲突的首选 |
| 1 | **买** | 第七卷 / 第九卷 | 钱、把柄 | 对方要价合理 |
| 2 | **吓** | 第一卷 / 第八卷 | 暴露意图 | 对方怕失去 |
| 3 | **抓** | 第六卷 | 人手、押运风险 | 需要活口 |
| 4 | **关** | 第三卷 | 长期成本、替身 | 需要时间 |
| 5 | **杀** | 第五卷 | 店规裂缝、因果 | 前四级全失败 |

**跳级规则**：

1. 必须灯主签字，写明"为什么不能停在前一级"。
2. 签字后，执行人终身不得升任掌灯人。
3. 跳级三次以上的人，自动进入第四卷的观察名单。
4. 掌灯人可以否决跳级；灯主每卷只能强行覆盖一次。

**主角优先规则**：

- 灯主的单，永远排在客户单前面。
- 客户单与灯主单冲突，客户单退回，或转介给别家；定金双倍返还。
- 客户想借暗账的手报私仇，第四卷先查；查实，永久拉黑。

**写作用法**：每场冲突先问"现在在第几级"。**级数越低，越像主角的手笔；级数越高，越像失控。**

## 5. 七步 SOP

| 步 | 动作 | 谁负责 | 产出 | 常见故障 |
|---|---|---|---|---|
| 1 | **立项** | 掌灯人 | 一张"待验单"：是灯主的单，还是客户的单 | 客户撒谎、目标其实是客人 |
| 2 | **验账** | 第一卷 + 第四卷 | 事实、风险、内鬼概率 | 孤证、假料、双面人 |
| 3 | **定价** | 第九卷 | 内账记成本；外账记报价、预算、押金 | 客户赖账、钱太脏 |
| 4 | **分卷** | 掌灯人 | 主卷 + 配合卷 | 卷灯退单、两卷抢单 |
| 5 | **执行** | 主卷 | 结果、痕迹、伤亡 | 失手、目击、规则反噬 |
| 6 | **平账** | 第九卷 + 第一卷 | 尾款、档案、销痕 | 尾款收不回、档案对不上 |
| 7 | **抚恤** | 掌灯人 + 第九卷 | 赔偿、退休、封口 | 家属闹、伤员被利用 |

**并账**：一单跨三卷以上时，成立临时"并账"，掌灯人指定一个主卷，其余配合。并账期间，主卷有决定权，但每个配合卷灯可以行使一次否决。**并账是九卷唯一被允许的横向接触，也是后宫"共事"的主战场。**

## 6. 钱、价目与抚恤

### 6.1 两种收入

| 类型 | 对象 | 怎么记 | 目标 |
|---|---|---|---|
| **内账** | 灯主 / 客栈 | 只记成本、人手、风险 | 把事办成，不追求盈利 |
| **外账** | 特定客户 | 报价 + 押金 + 尾款 | 覆盖成本，略有盈余 |

**没有保护费。** 暗账不收保护费，这是它与帮派的根本区别。

### 6.2 外账价目（示例，单位：宝）

| 服务 | 价格 | 备注 |
|---|---|---|
| 情报（浅） | 5–20 | 一条消息、一个地址 |
| 情报（深） | 50–200 | 需要线人、跨域、旧档 |
| 寻人 / 追账 | 20–200 | 按难度与距离 |
| 救援 / 转移 | 100–500 / 人 | 含路线、假身份 |
| 身份重做 | 50–150 | 含文书、口音、落脚 |
| 抓捕（活口） | 80–300 | 危险目标翻倍 |
| 关押 | 3 / 日（普通）；15 / 日（规则级） | 含伙食、看守、抑制 |
| 谈判 | 成交额的 10%，最低 30 | 见证人另付 |
| 暗杀 | 300–3,000 | 五成预付，不退款 |
| 舆论（一条故事） | 30–300 | 抹名 500 起 |
| 洗钱 | 8–15% | 血钱另算 |

> 对照《08_经济与货币》：1 宝 ≈ 云篆洲丰年 1 石粗粮。300 宝的暗杀，等于三百石粮——不是小数目。

### 6.3 成本结构

| 项 | 占比 | 说明 |
|---|---|---|
| 人力 | 40% | 灯影、线人、临时工 |
| 善后 | 20% | 封口、销痕、赔偿 |
| 抚恤 | 15% | 伤亡、家属、退休 |
| 装备与交通 | 15% | 武器、药剂、车马、船票 |
| 上缴客栈 | 10% | 暗账不是独立王国，它要向明账交租 |

**净利率 10–15%，且只对外账单算。** 内账可以亏，但暗账整体亏空不得超过明账净利的 **15%**。

### 6.4 抚恤与坏账

- 死者：200 宝 + 名字进永恒档案，永不销档。
- 伤者：50–100 宝 + 深渊免费治疗。
- 家属：100 宝/年，直到孩子成年。
- 坏账：失败的单子记为坏账。一卷三个月内三次坏账，卷灯停职；五次，封卷，人并入其他卷。
- **坏账不杀人不灭口。** 这是暗账与黑帮的最后一条分界线。

## 7. 招募、训练与退出

### 7.1 招募来源

- 住过店、无处可去的人。
- 被宗门除名、被教会放逐、被帮派抛弃的人。
- 有一技之长、但不想再靠那门手艺吃饭的人。
- **不招**：孩子、奴隶、被强迫的人、想靠杀人发财的人。

### 7.2 三道测试

| 测试 | 问什么 | 不过会怎样 |
|---|---|---|
| **守口** | 你能不能把一件事带进棺材？ | 不录用 |
| **守规** | 你能不能在能动手的时候不动手？ | 不录用 |
| **守账** | 你能不能说清楚每一分钱去哪了？ | 不录用 |

### 7.3 训练与身份

- 三个月：一个月学规矩，一个月学手艺，一个月跟着老灯影跑单。
- 每人有一个"夜名"（卷内代号）和一个"日名"（客栈岗位）。
- **夜名不带姓，日名不带卷。** 两套名字，两套人生。

### 7.4 晋升

```
灯影 → 灯芯 → 卷灯
```

卷灯需要三样：掌灯人推荐、灯主签字、第四卷清白证明。缺一样，只能做"代卷灯"。

### 7.5 退出

- 允许退出。店规第五条："来者是客，去者自由。"
- 退出给三样：一笔安家费、一个新身份（第二卷办）、一句承诺（不泄露）。
- 背叛的人，归第六卷抓，不归第五卷杀。**暗账不杀自己人，除非他自己先杀了自己人。**

### 7.6 与后宫四阶段

| 阶段 | 她在暗账里的身份 | 她得到什么 | 主角要付出什么 |
|---|---|---|---|
| 客 | 客户 | 问题被解决 | 一单的价钱 |
| 伙计 | 灯影 | 一个夜名、一份工 | 教她规矩 |
| 自己人 | 灯芯 / 代卷灯 | 带人的权 | 允许她犯错 |
| 定契 | 卷灯 / 卷印 | 退单权、分账权 | 分权、分账、被她否决 |

> **人选留白**：上表只写"阶段→身份"，不写具体人名。谁成为灯影、灯芯、卷灯，由后续人物卷决定；本文件不预设。

## 8. 与店规、诸域、后宫的关系

### 8.1 店规边界

| 店规 | 对暗账的约束 | 破例的代价 |
|---|---|---|
| 店内不得动武 | 所有行动在"门外三步" | 店规失效一次，暗账全体停摆一月 |
| 欠账者不得离店 | 暗账不替客人还账 | 客人被扣，暗账只能谈，不能抢 |
| 隐瞒身份者茶必苦 | 暗账的人进店也要喝茶 | 自己人先现形 |
| 店内所言店外不作数 | 暗账不利用客人的秘密 | 一旦利用，永恒档案被封 |
| 来者是客去者自由 | 不强行留人、不强行带人 | 第二卷卷印作废 |

**核心张力**：暗账靠"店规之外"的手段活着，但它的合法性来自"店规之内"的客栈。**它越强，越容易把客栈拖下水；它越守规矩，越办不成事。**

### 8.2 与八域的对口

| 域 | 对口机构 | 冲突点 |
|---|---|---|
| 云篆洲 | 青冥宗、天衡仙朝 | 第五卷被视为魔道；第二卷的偷渡被通缉 |
| 太荒 | 九黎部、祖巫遗族 | 第二卷的救援会碰到"人牲"；第三卷关过祖血觉醒者 |
| 铁枢 | 审计院、枢议会 | 暗账是"未登记组织"；第四卷与审计院同源 |
| 蒸枢 | 锅炉总工会 | 第九卷的地下钱庄与工会基金冲突 |
| 辉庭 | 圣廷、灰袍修会 | 第五卷与第三卷被视为异端；第八卷被视为"假见证" |
| 畸城 | 白蜡财团、铁牙帮 | 第六卷与第九卷抢生意 |
| 无言乡 | 守则局、收容队 | 暗账是"条文外组织"；第三卷的囚犯可能被收容队追讨 |
| 灰原 | 横贯铁路公司、警长 | 第六卷的赏金与铁路公司的私刑冲突 |
| 万宝楼 | 商会 | 第九卷与第一卷是竞争关系；万宝楼也可能雇暗账 |

### 8.3 与后宫：白天与黑夜

**三条原则**：

1. **不是每个自己人都进暗账。** 明面必须留人——客栈需要一张干净的脸，暗账需要这张脸做掩护。
2. **卷灯不是按职位自动分配的。** 白天是厨师、账房、护院，不等于夜里就是卷灯；反过来，夜里能掌灯的人，白天也可能只是个跑堂。
3. **卷灯人选由灯主与掌灯人另行商定。** 本文件只定"夜间职位"的存在与权限，不锁定任何名字。

**夜间职位的意义**：

- 给有独立目标的人一个"非她不可"的位置；
- 给"共事"一个结构性的理由：并账任务必须两卷以上合作；
- 给"定契"一个可见的凭证：卷印与退单权。

**暗护与明帮各半**：

幕后流最容易犯的错，是让女主永远被暗中保护。暗账的任务只能承担一半的情感推进；另一半必须由主角当面完成——对峙、扛责、道歉、拒绝。

## 9. 十个故事钩子

1. **第一单**：第九卷翻出一张"没有收货人的货单"，收货人写的是灯主自己的名字。
2. **并账**：第五卷与第三卷同时接到同一个目标——一个要杀，一个要关；两卷第一次正面冲突。
3. **退单**：第二卷卷灯拒绝转移一个"该被交出去"的人；掌灯人不能强迫，只能自己想办法。
4. **内鬼**：第四卷查出暗账里有一个"被换过"的人；掌灯人必须审自己带进来的人。
5. **假旗**：第八卷替客户编了一个故事，故事自己长出了信徒；卷灯要亲手杀死自己的故事。
6. **黑牢**：第三卷关的东西开始跟看守说话，叫她"医生"，还记得她十年前的名字。
7. **赎金**：第七卷谈成一桩绑架，却发现肉票是自愿被绑的——他想用赎金买自己的自由。
8. **资金**：第九卷发现暗账一半的资金来自万宝楼，而万宝楼在替某个域洗一笔灭门的钱。
9. **剑**：第五卷接到一个"该杀"的目标，发现对方是宗门误判的另一个受害者。
10. **灯主**：有人开始查"灯主"，而唯一知道灯主身份的是掌灯人——掌灯人第一次被人用命来换这个秘密。

## 10. 写作检查表

写任何一单暗账任务，过这五问：

1. **这单是谁的账？** 是灯主要办的事，还是客户要办的事？两者冲突时，谁优先？
2. **现在在第几级？** 为什么不能停在上一级？跳级是谁签的字？
3. **哪一卷负责？** 卷灯的独立目标与这单冲突吗？她有没有可能退单？
4. **店规有没有被碰？** 如果碰了，代价落在谁头上？
5. **这单让谁留下来了？** 如果答案只是"主角很帅"，删掉重写。

五问答不全，暗账就只是个换皮的黑帮。
