# 参考书单 · 剧情线（补）：幕后流

> 版本：v0.1
> 定位：本书的**默认叙事模式**，不是可选装饰。
> 置信度：● 高 / ○ 中（建议核对）/ ◇ 原型、方法论或非网文参考
> 说明：幕后流在中文网文里是"高热度、少纯血"的类型，多数作品是"幕后+其他"的混合。因此本单采用"作品 + 原型 + 方法论"三段式，共 120 条。

---

## 0. 定义与判断标准

### 0.1 什么是幕后流

**主角不站到台前，通过信息、资源、规则、组织、代理人影响世界。**
爽点不是"我打赢了"，而是"事情成了，但没人知道是我做的"。

### 0.2 三个判断标准

| 标准 | 问题 | 不合格的表现 |
|---|---|---|
| **不露面** | 主角是否长期不在冲突现场？ | 每场架都亲自打 |
| **有代理** | 是否有人替他执行？ | 所有事都自己干 |
| **有信息差** | 读者知道、局中人不知道？ | 主角和对手信息完全对等 |

三条都满足，才是幕后流。只满足一条，是"隐藏实力流"。

### 0.3 与其他类型的关系

| 类型 | 与幕后流的区别 |
|---|---|
| 隐藏实力流 | 主角在场上，只是装弱 |
| 马甲流 | 是幕后流的一种手法，不是全部 |
| 权谋流 | 侧重政治博弈，可以没有"代理人" |
| 无限流 | 侧重副本，幕后性看写法 |
| 经营流 | 天然适合幕后，因为老板本来就不上场 |

## 5. 幕后流技法（20）

| # | 技法 | 说明 | 本书怎么用 |
|---|---|---|---|
| 101 | **马甲分层** | 一个主角，多个互不承认的身份 | 东家 / 驿丞 / 某域商人 |
| 102 | **代理人链** | 主角→伙计→外部势力→目标 | 东家吩咐跑堂，跑堂找帮派 |
| 103 | **信息差三拍** | 读者知道→局中人不知→揭晓 | 客人以为是巧合，读者知道是安排 |
| 104 | **规则设计** | 不阻止，只让对手在规则里自撞 | 店规第一条 |
| 105 | **造神三步** | 做一件事→讲成故事→让人自己传 | 说书人写话本 |
| 106 | **误会流** | 对手自己脑补出你的强大 | 客人把"破店"当高人隐居 |
| 107 | **长线回收** | 十步前埋，十步后收 | 分店网络 |
| 108 | **露一角** | 每卷让读者看见一次真实力 | 一次破规战 |
| 109 | **前台视角** | 用客人/伙计的眼睛看主角 | 单元剧第一人称段落 |
| 110 | **失败布局** | 布局失败一次，张力才成立 | 某次算错人 |
| 111 | **双身份** | 明面身份与暗面身份 | 驿丞与"幕后东家" |
| 112 | **舆论战** | 不打赢，先赢说法 | 说书人对教会 |
| 113 | **供应链布局** | 控制货源比控制人更狠 | 分店卡住某域的物资 |
| 114 | **情报网** | 跑堂、账房、掮客三线 | 万象簿客源模块 |
| 115 | **借刀** | 让敌人的敌人出手 | 两域冲突中做中立人 |
| 116 | **养寇** | 留着对手，比消灭更有用 | 不急着打垮同行 |
| 117 | **造势** | 先把声势做起来，再做事 | 开业前的传闻 |
| 118 | **退居幕后** | 主动交出一线，换长期安全 | 让大掌柜出面 |
| 119 | **责任反转** | 让对手承担自己布局的后果 | 店规公示后，违规者自误 |
| 120 | **布局失败美学** | 失败留下伏笔，不是白输 | 一次错判换来一条新线 |

## 6. 与本项目的映射

| 幕后流要素 | 本书已有的载体 | 是否需要新增设定 |
|---|---|---|
| 不出面 | 店规禁止店内动武 | 已有 |
| 代理人 | 十大职位 | 已有 |
| 信息差 | 万象簿·客源 | 已有 |
| 规则设计 | 店规 | 已有 |
| 造神 | 说书人、口碑 | 已有（可强化） |
| 多重身份 | 东家 / 驿丞 | 需补：马甲清单 |
| 长线布局 | 分店网络、商路 | 已有 |
| 前台视角 | 单元剧客人视角 | 需补：每卷一个"前台人物" |

**结论**：幕后流不需要新增世界观，只需要补两份东西——**马甲清单**和**前台视角人物表**。这两份可以等角色阶段再做。

## 7. 失败模式

| # | 失败模式 | 症状 | 解法 |
|---|---|---|---|
| 1 | 只下棋不收子 | 连续五章布局，读者不知道在干嘛 | 每 3–5 章回收一次 |
| 2 | 主角消失 | 读者忘了主角是谁 | 每卷"露一角" |
| 3 | 全知全能 | 主角什么都算到 | 布局必须失败一次 |
| 4 | 上帝视角 | 全是旁白，没有人物视角 | 用前台人物 |
| 5 | 爽点延迟过长 | 三十章才爽一次 | 小布局小回收 |
| 6 | 代理人太听话 | 伙计像工具人 | 代理人要有私心 |
| 7 | 马甲混乱 | 读者记不住谁是谁 | 马甲不超过三个 |
| 8 | 幕后变成逃避 | 主角永远不承担责任 | 关键节点必须亲自出面 |
| 9 | 信息差作弊 | 主角突然知道一切 | 情报必须有来源与成本 |
| 10 | 布局无代价 | 赢了没损失 | 每次布局都要付代价 |

## 8. 写作检查表

每写完一个幕后单元，过这六问：

1. 这一局是谁在台前？读者能代入谁？
2. 主角做了什么？只做了一件事吗？（超过三件就太全知）
3. 信息从哪里来？付了什么代价？
4. 局中人为什么没看穿？理由成立吗？
5. 这一局失败了什么？
6. 回收周期是几章？

六问答不全，这章就是"作者在自嗨"。
