# 命名谱系

> 版本：v2.0（修正版）
> 定位：给每个名字找到它所属的文化圈，而不是把所有名字都塞进一套中国古法。
> 一句话：**名必须长在它自己的文化里；五法只属于中国谱系的三类，其他域各有各的取名逻辑。**

---

## 0. 修正说明：上一版错在哪

v1.0 把中国古代取名的五法（因象与实、托意与志、借典与文、循序与制、玩音与形）当成"全世界通用规则"，结果出现了文化错位：

- 科技域被命名为"绳墨"——用一个中国古代匠人词，去命名一个契约与算法文明；
- 蒸汽域被命名为"洪炉"——引《庄子》"天地为大炉"，但这一域的人不信庄子，只信锅炉与工时；
- 西幻域被命名为"誓庭"——用了中国官衙的"庭"，而它本该是圣廷与骑士的译名体系；
- 废土域被命名为"烬原"——"烬"字带着中国式的劫火余烬，而这一域只有枪、铁轨和灰；
- 怪谈域的管理机构被命名为"定章司"——一个中国古官署，去管 SCP 式收容与规则条文。

**这不是风格问题，是文化归属错了。**
v2.0 的边界：

| 层 | 范围 | 取名依据 |
|---|---|---|
| **世界层** | 世界、律海、错律带、主店、纪元、跨域事件 | 中性、描述、约定；不套任何一域的文化 |
| **中国谱系域** | 云篆洲（修仙/修真）、太荒（洪荒）、武侠江湖 | 五法：象、意、文、制、音形 |
| **其他六域** | 铁枢、蒸枢、辉庭、畸城、无言乡、灰原 | 各域自己的文化逻辑 |

本版恢复的域名：**铁枢、蒸枢、辉庭、畸城、灰原**。
保留的域名：**云篆洲**（修仙域，五法适用）、**太荒**（洪荒，五法适用）、**无言乡**（怪谈，按子类）。
保留的世界层名：**万相界 / 拼陆、律海、天倾、错律带、无主墟、万律、无籍驿、共鸣、三年沉默、初逢之乱、错律公约、律海退潮**。

## 1. 三层命名

### 1.1 世界层：跨域通用名

这些名字不属于任何一域，是地图、商队、条约、史书共用的"普通话"。
它们应当**中性、可描述、可约定**，不引某一域的典，不避某一域的讳。

| 名字 | 为什么这样取 | 命名者 |
|---|---|---|
| **万相界 / 拼陆** | 官方名"万相"取万物之象；俗称"拼陆"直说大陆是碎片拼起来的 | 舆图司 / 行商 |
| **律海** | 规则如水，汇而成海；是比喻，不是典故 | 早期立规者 |
| **天倾** | 天塌向西北；先有灾变，后有文人加的典故 | 幸存者 |
| **错律带** | 两套规则在这里相错；地理描述 | 八域舆图 |
| **无主墟** | 无主之墟；规则最乱之地 | 探险者 |
| **万律** | 万条规则之城；与"万象簿"分工：城存规则，簿记账 | 立规者 |
| **无籍驿** | 不属任何一域户籍；无籍者皆可投。云篆洲所起，后成跨域通名 | 历代东家 |
| **共鸣** | 两套规则互相借力；借用物理词，不做玄学解释 | 八域学者 |
| **三年沉默** | 天倾后所有力量失灵三年；直说 | 史官 |
| **初逢之乱** | 八域第一次大规模接触；直说 | 史官 |
| **错律公约** | 八域签的"不越界"公约；近代条约语 | 八域使团 |
| **律海退潮** | 律海潮汐下落；自然描述 | 云篆洲天官 |
| **凝律纪 / 驿路纪 / 炉轨纪 / 枯潮纪** | 史家分期：规则凝定 / 驿路兴起 / 炉与轨 / 枯潮 | 后世史官 |
| **洪荒余纪** | 天倾后残余的洪荒；只用于太荒一系 | 太荒遗族口传 |

**世界层不搞"三名制"。** 一个跨域地名只需要一个通用名；俗称可以有，但不强求正式/俗称/旧名三层。

### 1.2 中国谱系：五法适用

只有三类用五法：**云篆洲（修仙/修真）、太荒（洪荒）、武侠江湖**。
它们的共同点：社会以道统、宗门、宗门之外的江湖、祖巫与部落为核心；命名本身是权力、辈分、避讳与用典的一部分。

### 1.3 其他六域：各用各的逻辑

| 域 | 文化原型 | 命名逻辑 | 关键词 |
|---|---|---|---|
| **铁枢** | 信息资本主义 / 技术官僚 | 功能名、编号、缩写、分级 | 枢、网、信用、权限、底城 |
| **蒸枢** | 维多利亚工业 / 工团 | 材料、设备、工时、工会、公司 | 炉、阀、压、铆、煤、七城 |
| **辉庭** | 西欧封建 / 教会 | 译名感、誓约、圣物、塔与冠 | 圣、誓、冠、塔、王领、修会 |
| **畸城** | 当代都市 / 地下亚文化 | 诨名、财团名、药物名、编号 | 畸、裂、帮、财团、抑制剂 |
| **无言乡** | 规则怪谈四子类 | 按子类分别命名 | 守则、编号、阴司、序列、无名 |
| **灰原** | 美国边境 / 废土 | 直白地名、公司名、军团编号 | 镇、井、铁轨、白骨、军团 |

**武侠江湖**不是独立域，它是云篆洲与太荒内部的江湖层；命名用五法，但加一条江湖规则：**诨号是挣来的，不是自封的。**

## 2. 中国谱系：五法怎么用

### 2.1 五法提要

| 法 | 做法 | 古人例 | 本世界例 |
|---|---|---|---|
| **因象与实** | 直接捕捉特征、环境、形状 | 孔子名丘；洛阳；十竹斋 | 太荒、芜洲、剑冢 |
| **托意与志** | 把愿望、德行、吉祥固定进名字 | 屈原字原；赵云字子龙 | 天衡仙朝、青冥宗 |
| **借典与文** | 引典籍诗文，借文化合法性 | 男《诗经》女《楚辞》；年号取《周易》 | 云篆洲（云篆）、万宝楼 |
| **循序与制** | 守秩序、避讳、字辈、命名权 | 《左传》六禁忌；避讳；字辈谱 | 云篆洲避"衡"；青冥宗字辈 |
| **玩音与形** | 谐音、拆字、叠字、数字 | 甄士隐/贾雨村；"宋"拆"本穴" | 江湖诨号、剑冢 |

### 2.2 云篆洲（修仙/修真）

- **域名**：云篆洲。旧称玄洲。
- **字面**：九州浮空，云海如篆。
- **典故**：道教"云篆"为天书、符箓之文。
- **寄托**：修仙即读天之文；所以这一域盛产符箓、阵法、剑诀。
- **三名**：正式"云篆洲"；俗称"云洲"；旧名"玄洲"（前朝典籍仍用）。
- **避讳**：避"衡"（天衡仙朝）；宗门表面遵，私下各叫各的。
- **内部名**：天衡仙朝、青冥宗、万宝楼、散修盟、剑冢、芜洲、无籍驿。

### 2.3 太荒（洪荒）

- **域名**：太荒。保留。
- **三层**：字面是极远极古的荒野；典故接《山海经》大荒谱系；寄托是"力即理，古不变"。
- **特例**：诸部不立文字，**没有正式名**；"太荒"是外域史官给的。
- **内部名**：九黎部、万兽庭、血原、骨山、祖巫、十二巫庭。
- **避讳**：无。没有国家，就没有避讳。

### 2.4 武侠江湖

- **范围**：云篆洲的镖局、门派、武林大会；太荒的蛮武、角斗场。
- **命名法**：
  - **门派**：字辈 + 山门名。例：青冥宗"青、冥、守、一、剑"五辈。
  - **诨号**：江湖人送，不自己取。例："铁灯""半截""一阵风"。
  - **堂号**：镖局、商号用"堂/号/楼"。例：万宝楼、镇远镖局。
  - **禁忌**：不拿朝廷名号做诨号；不冒用宗门字辈。
- **三名**：本名、诨号、门派道号，可以并存。

## 3. 其他六域：各自的命名规范

### 3.1 铁枢（信息 / 契约 / 技术官僚）

**逻辑**：功能优先，名字是"编号与权限"的一部分。

- **域名**：铁枢。"枢"是枢纽，不是典故；"铁"是材料与工业感。
- **政体**：械律联邦。
- **设施**：枢网、枢心、枢议会、枢语。
- **人名**：编号 + 职级。例：P3-17、审计员 04、底城 D-9。
- **地名**：上城、外环、底城、铁幕、第七码头、静默区。
- **机构**：棱镜公司、长夜重工、恒基集团、审计院。
- **事件**：技术裂变。
- **禁用**：用典、避讳、字辈、诗意地名。**技术域的名字可以难听、可以像工牌，这是真实感。**

### 3.2 蒸枢（蒸汽 / 工业 / 工团）

**逻辑**：材料 + 设备 + 工时 + 工会；名字是"车间与合同"的一部分。

- **域名**：蒸枢。"蒸"是蒸汽，"枢"是枢纽；直说。
- **城市**：七城；炉心、铆钉、云港、灰仓。
- **机构**：锅炉总工会、七城议会、飞空艇商会、私煤党。
- **货币**：工时券、锅炉票。
- **人名**：诨名 + 工种。例：铁娘子·岑三娘、老铆、三号炉工。
- **事件**：锅炉战争、双枢协定。
- **禁用**：庄子、洪炉、炉墨之类中国文人式命名。**这一域的名字应该有煤灰、机油和工时味。**

### 3.3 辉庭（西幻 / 封建 / 教会）

**逻辑**：译名感；圣、誓、冠、塔、王领；拉丁/日耳曼封建气息。

- **域名**：辉庭。不是中国官衙的"庭"，是"光耀之庭"的译名感。
- **教会**：圣廷、七誓、七塔、灰袍修会。
- **地名**：白冠城、三王冠、朝圣道。
- **制度**：赦罪券、封爵、骑士团。
- **人名**：名 + 姓 + 封号。例：薇拉·白冠、黛安·灰袍。
- **事件**：七誓定稿、赦罪券丑闻。
- **禁用**：中国官署名（司/衙/局）、字辈、避讳。**这一域可以有"圣"与"誓"，但不能有"尚书省"和"礼部"。**

### 3.4 畸城（异能 / 当代都市 / 地下）

**逻辑**：都市亚文化；帮派诨名、财团名、药物名、编号。

- **域名**：畸城。别名"裂城""地下城"。
- **地名**：裂口、下层、铁桥头、白蜡街。
- **势力**：白蜡财团、铁牙帮、无面帮。
- **物品**：抑制剂、畸变药剂、义体零件。
- **人名**：诨名 + 真名。例：铁牙·阿七、无面、白蜡医生。
- **事件**：裂口事件。
- **禁用**：古典典故、诗意地名。**这一域的名字要像贴在墙上的寻人启事和药品标签。**

### 3.5 无言乡（规则怪谈，按子类）

**逻辑**：不强行统一；四个子类各有命名传统。

| 子类 | 命名逻辑 | 例 |
|---|---|---|
| **条文型**（SCP 式） | 现代收容官僚：编号、站点、告示、守则 | 守则局、编号 0-17、站点、收容队 |
| **民俗型**（中式志怪） | 阴司官署、纸人、冥婚、城隍 | 人间司、城隍衙、纸人、赶尸 |
| **深渊型**（克苏鲁） | 不命名；只用禁忌、无名、不可名状 | 无名之物、旧日、深渊 |
| **序列型**（诡秘式） | 序列名、途径、扮演 | 序列 9、途径、扮演 |

- **域名**：无言乡。这是民俗型给整片雾域起的名字；其他子类并不认这个"乡"，但对外只能用这个通名。
- **管理机构**：守则局（现代收容官僚），不是"定章司"。
- **事件**：入册之夜。
- **禁用**：用一种命名法强行统一四个子类。**条文型不该有城隍，民俗型不该有站点编号。**

### 3.6 灰原（西部 / 废土）

**逻辑**：美国边境与废土；直白地名、公司名、军团编号、赏金诨名。

- **域名**：灰原。直说：灰烬之原。
- **地名**：七镇、白骨原、铁棺城、盐井、灯箱镇。
- **机构**：横贯铁路公司、七镇联盟、赏金行会。
- **军事**：第十三军团。
- **人名**：诨名 + 姓。例：赏金客"老枪"、铁路工头。
- **事件**：第十三军团失联、铁路争夺。
- **禁用**：古典典故、诗意地名。**这一域的名字要像路牌、通缉令和铁路时刻表。**

## 6. 命名纪律

1. **先定文化圈，再取名。** 这个名字属于哪个域？这个域的人会这样说话吗？
2. **五法只用于中国谱系三域**（云篆洲、太荒、武侠江湖）。其他域不得用典、避讳、字辈。
3. **世界层用中性/描述/约定**，不套任何一域的文化。
4. **域内命名必须与力量来源、社会形态一致。** 技术官僚不会用庄子取名，工团不会用尚书省取名。
5. **一域最多两种命名法。** 混太多会变成大杂烩。
6. **科技、工业、都市、废土可以功能化、编号化、难听。** 那是真实感，不是命名失败。
7. **西幻用译名感，不用中国官署。**
8. **怪谈按子类分别命名，不强行统一。**
9. **跨域事件用中性词。**
10. **新名必须能回答"谁起的、给谁用"。**

## 7. 自检五问

| 问 | 答不上来时 |
|---|---|
| 这个名字属于哪个文化圈？ | 回去看该域的力量来源与社会形态 |
| 这个域的人会这样命名吗？ | 名字是作者的语言，不是角色的语言 |
| 它是不是借了不属于这个域的文化？ | 删掉典故，换成本域的材料/制度/职业词 |
| 跨域使用时是否中性？ | 换成描述词，不用任何一域的典 |
| 旧名/别名是否保留？ | 没有别名的名字，缺历史与立场 |
