# 参考库 · 总说明与索引

> 版本：v1.0 ｜ 建立日期：2026-10-24
> 适用域：**云篆洲**（修仙 / 修真）、**太荒**（洪荒）、**武侠江湖**（云篆洲与太荒共用的 L1 流派层）
> 定位：不是推荐榜单，是**设定工程的原料库 + 去重依据 + 溯源底账**。
> 一句话：**先看别人怎么写，再决定自己不怎么写。**

## 0. 这次为什么要重建参考库

旧版《03_参考书单》解决的是"有哪些网文可看"，没有解决三个更根本的问题：

1. **只看网文，会把网文的集体套路当成世界规律。** 洪荒流、修仙流、武侠流各自的套路，很多来自某几本头部作品的互相模仿，不是神话、历史或社会本身的逻辑。
2. **没有去重。** 灵根、宗门、金丹、天劫、祖巫、兽潮、武林大会……这些母题在不同作品里反复出现，旧版只做了"检索入口"，没有回答"我们到底采用哪一个版本、为什么"。
3. **没有跨媒介。** 影视的视觉调度、游戏的系统反馈、成人向作品的关系张力，都是小说给不了的。只读小说，写出来的世界会"只有设定，没有镜头"。

所以本库按 **四个题材 × 六个媒介** 重建：

| 题材 | 覆盖内容 | 主要服务 |
|---|---|---|
| **洪荒** | 开天、祖巫、巫妖、血脉、巨兽、部落、兽潮、祖庙 | 太荒 |
| **修仙** | 仙侠、飞升、仙门、仙侣、仙侠情感、仙庭 | 云篆洲的表层与高端客源 |
| **修真** | 境界、资源、凡人流、宗门经营、炼丹炼器、灵根 | 云篆洲的底层逻辑与经营线 |
| **武侠江湖** | 镖局、门派、帮会、武林大会、江湖规矩、低武生态 | 云篆洲的芜洲、太荒的蛮武、客栈的伙计与护院 |

> **"修仙"与"修真"的分界**：本书不做学术定义，只做写作分工。
> **修仙**偏"仙"——飞升、仙庭、仙侣、宿命、审美；**修真**偏"真"——资源、境界、寿命、组织、凡人如何在修士世界里活。云篆洲两者都要，但**主店所在的芜洲更偏修真，仙朝与宗门高层更偏修仙**。

## 1. 收录口径

### 1.1 作品口径

- **文学作品**：以中国古典神话、志怪传奇、武侠/仙侠文学、现代神话重述为主；不收与研究著作混在一起。研究著作单列，不计入"100 部"。
- **影视**：以中国（含港台）神话、仙侠、武侠影视为主；海外作品只进"结构参考"栏，不计入"100 部"。
- **游戏**：以中国仙侠、修真、武侠、洪荒题材游戏为主；经营/模拟类只收与"客栈、门派、部落经营"直接相关的；海外机制参考单列，不计入"50 部"。
- **NSFW**：只收**成人向、虚构、角色均为成年人**的作品；只做书目与叙事功能记录，不摘录露骨内容，不提供获取渠道。不收涉及未成年人的作品，不收真人偷拍、非自愿内容。

### 1.2 置信度标记

沿用旧版标记，并加一档：

| 标记 | 含义 | 用法 |
|---|---|---|
| **●** | 高：作品名、作者、年代可确认 | 可直接引用 |
| **○** | 中：作品存在，但作者/年代/版本可能有偏差 | 引用前建议核对 |
| **◇** | 方向：不是具体作品，是原型、类型或结构参考 | 只用于方法论，不写成"某作品" |

> **纪律：宁可标 ○，不许编书名。** 本书单里凡是标 ○ 的，写作时只取"类型功能"，不取具体情节；需要精确引用时先核对。

### 1.3 数量口径

- "不少于 100 部"按**去重后的独立作品**计，不以改编、续作、同名影视重复计数。
- 同一作品的多版改编（如《射雕》多个电视剧版本）只算一部"作品"，不同版本放在同一行的"版本"列里，作为**表演/调度参考**，不重复计数。
- 系列作（如《仙剑》系列）按"系列"算一部，具体单作在备注里列；这样避免用续作灌水。

## 2. 去重与融合：五步法

本库不是"看完就写"，而是强制走五步。每一步都有产出，产出直接进 `07` 和 `08`。

### 第一步：拆母题，不拆情节

把作品拆成**可迁移的设定单元**，而不是记剧情。

| 拆什么 | 例子 |
|---|---|
| 世界规则 | 灵气从哪来、规则有没有主人、力量要不要付代价 |
| 社会结构 | 谁掌权、阶层怎么分、法律对谁有效 |
| 空间 | 山门、坊市、秘境、祖庙、驿站、客栈 |
| 人物功能 | 引路人、执法者、商贩、叛徒、隐世高手 |
| 场面 | 测灵根、渡劫、拍卖会、武林大会、兽潮、血祭 |
| 物件 | 灵石、法帖、剑冢、骨器、灵票、客栈招牌 |
| 关系 | 师徒、道侣、主仆、债主、血亲、部落盟约 |

### 第二步：统计频次，找"集体套路"

同一母题在 3 部以上作品反复出现，且写法高度相似，就标记为**高套路**。

- 高套路不等于不能用，而是**不能照原样用**。
- 处理方式只有四种：**保留并深化 / 合并两个母题 / 反转其功能 / 删除**。

### 第三步：功能分析，不问"是什么"，问"在故事里干什么"

例：

| 母题 | 表面是什么 | 真正功能 | 可替代方案 |
|---|---|---|---|
| 测灵根 | 测天赋 | 制造阶级与一次公开羞辱 | 测"纸墨亲和"、测"承印量"、测"名字的重量" |
| 天劫 | 雷劈 | 给强者收账、制造公开事件 | 律海来收账、天劫是"对账日" |
| 武林大会 | 比武 | 让所有势力同场、制造排名 | 驿市、拍卖会、角斗、听证会 |
| 兽潮 | 怪物攻城 | 强迫各方合作、制造开业劫 | 大地免疫反应、规则排异 |

### 第四步：去重，先做减法

每一条最终设定，必须能回答：

1. 它在至少 3 部参考作品里出现过吗？
2. 我们保留的是它的**功能**，还是它的**外壳**？
3. 如果删掉它，故事会缺什么？
4. 它和本域另外三条设定是否重复？

答不上来，就删。**设定不是越多越好，是越互相咬合越好。**

### 第五步：融合，做"一域一隐喻"

每个域只允许一个**总隐喻**，所有设定都往它上面长。

| 域 | 总隐喻 | 一句话 |
|---|---|---|
| **云篆洲** | **天书写在云上，人把命刻进字里** | 修仙是读天书、改天书、最后把自己写成天书 |
| **太荒** | **这片大地是一具还没死透的祖巫** | 部落是器官，兽潮是免疫，雷暴是排异，同化是消化 |

总隐喻不是修辞，是**约束**：任何新设定，先问"它长在这具身体的哪个部位/这本字的哪一页"。长不上，就不进。

## 4. 从参考到设定：本项目的十条取舍原则

1. **能用社会解释的，不用天赋解释。** 灵根不是"天选"，是"纸的质地"；宗门不是"正道"，是"垄断了测纸标准的行会"。
2. **能给价格的，不给概念。** 因果不是玄学，是账；天劫不是神罚，是收账。
3. **能落到店的，不落到山。** 所有设定先问"它怎么变成客源、菜品、房间、风险"。
4. **高套路必须反转一次。** 测灵根、渡劫、武林大会、兽潮，全部要有一个"和读者预期不一样"的用法。
5. **一个域只留一个总隐喻。** 云篆洲是"字"，太荒是"尸体"；不许再塞第二个总隐喻。
6. **强者必须有弱点，弱者必须有尊严。** 不写"境界碾压一切"，不写"野蛮=落后"。
7. **不写无限升级。** 力量提升必须带来经营/关系/政治上的新麻烦。
8. **不写"现代知识降维打击"。** 主角的现代知识只能用来"设计制度"，不能用来"造科技"。
9. **不写人牲、不写未成年人、不写非自愿。** 这是全书的伦理底线，也是 NSFW 参考库的边界。
10. **每条设定都要能溯源。** 说不清从哪来的设定，要么删，要么标"原创待验证"。
