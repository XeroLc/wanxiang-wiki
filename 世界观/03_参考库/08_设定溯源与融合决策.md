# 设定溯源与融合决策

> 版本：v1.0 ｜ 建立日期：2026-10-24
> 用途：把 `02_域志/云篆洲.md` 与 `02_域志/太荒.md` 的每一条核心设定，挂回参考库，回答三个问题：
> **从哪来？改了什么？为什么？**
> 一句话：**没有溯源的设定，就是拍脑袋。**

---

## 0. 方法

每条设定按六列记录：

| 列 | 含义 |
|---|---|
| **设定条目** | 最终写进域志的设定 |
| **来源** | 参考库中的作品/类型/母题（用 `01`–`07` 的编号或名称） |
| **原始功能** | 它在原作/母题里干什么 |
| **去重判断** | ★ 采用并深化 / ◐ 合并改造 / ⟳ 反转 / ✕ 删除 / ◇ 氛围 |
| **融合结果** | 本书的具体写法 |
| **落点** | 域志的章节 |

**判断标准**：

- 如果一条设定在 3 部以上作品里以同样方式出现 → 必须 ◐ 或 ⟳。
- 如果一条设定只在一部作品里出现，且不是该作品的核心 → 只作 ◇，不进正文硬设定。
- 如果一条设定无法回答"对客栈有什么用" → 删除。

1. 不写"野蛮=落后"（太荒有自己完整的逻辑）。
2. 不写"无脑蛮力碾压"（力量有同化代价）。
3. 不写"主角用现代知识驯服巨兽"（只能设计制度）。
4. 不写"人牲"（正文不写，只作为威胁）。
5. 不写"祖巫复活"（是"醒"，不是复活）。
6. 不写"盘古/女娲/鸿钧"（神名失传）。
7. 不写"妖族天庭"（妖族是散居）。
8. 不写"兽潮=怪物攻城"（是免疫反应）。
9. 不写"血脉=遗传"（是契合度）。
10. 不写"决斗=比武"（是承载力测试）。
