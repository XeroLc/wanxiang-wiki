# 母题库与去重表

> 版本：v1.0 ｜ 建立日期：2026-10-24
> 用途：把 `01`–`06` 六类参考作品拆成可比较的"设定单元"，逐条判断 **保留 / 合并 / 反转 / 删除**。
> 一句话：**不要问"这个设定酷不酷"，要问"它在故事里干什么、别人已经怎么写烂了"。**
> 标记：**★ 采用并深化**｜**◐ 合并改造**｜**⟳ 反转功能**｜**✕ 删除**｜**◇ 仅作氛围**

---

## 0. 怎么用这张表

写新设定时，先查这张表：

1. 这个母题在"常见写法"里吗？在 → 看"去重判断"。
2. 去重判断是 ✕ → 不要写；是 ⟳ → 可以写，但必须反着写。
3. 本项目用法是空 → 说明还没决定，先别写进正文。

**三条铁律**：

- 一个母题最多保留一个"功能"，不要既想写阶级又想写爽点。
- 高套路（出现 3 部以上）必须至少改造一次，否则读者会预判。
- 删除的母题不要再从别的作品里偷偷捡回来。
