# 地理总图

> 版本：v0.3
> 定位：给历史事件一个"发生在哪"，给商路一个"走多久"，给新域留出"插在哪"。
> 原则：**地图不是画满的，是留白的。** 已探明区域约占七成，其余是扩展槽。

---

## 0. 读图规则

### 0.1 坐标系

- 全图采用**方格坐标**：横轴 X、纵轴 Y，单位"格"。
- **1 格 ≈ 100 里**（约 50 公里）。
- 已探明大陆约 **12 格 × 12 格**，即 1200 里见方。
- 坐标只用于写作与数据管理，不要求读者记。

### 0.2 地图分层

| 层 | 内容 | 是否可扩展 |
|---|---|---|
| L0 底图 | 拼陆轮廓、海、空白 | 固定 |
| L1 域层 | 八域的位置与范围 | 可追加（走槽位） |
| L2 裂缝层 | 错律带、无主墟 | 可局部生长 |
| L3 交通层 | 铁路、航线、管道、驿道 | 随剧情增加 |
| L4 未探明层 | 六个扩展槽、三块沉眠碎片 | 预留 |

### 0.3 三条读图约定

1. **图是示意，不是等比例。** 文学优先，别拿尺子量。
2. **距离是"官方口径"**，实际耗时受天气、律蚀、关卡影响。
3. **没有标注的地方，就是没人去过。** 留白是设定，不是遗漏。

### 2.2 八域的空间逻辑

- **太荒是最大的一块碎片**，所以它占西北。
- **蒸枢与铁枢同源**，被错律带劈在东北与东南，隔着中央裂缝互相对望。
- **云篆洲是唯一的"浮空群岛"**，因为它整块碎片最轻，至今还在缓慢上浮。
- **灰原是唯一"碎没了"的碎片**，所以它最低、最平、最空。
- **辉庭在海那边**，与大陆只靠朝圣道与海路相连。
- **畸城在地下**，因为它不是碎片，是**裂口塌出来的城市**。
- **无言乡不在版图上**，它是错律带里的一团雾，地图只能标个大概。

## 3. 错律带：不是环，是裂缝网

### 3.1 五条主裂缝

| 裂缝 | 走向 | 连接 | 特征 |
|---|---|---|---|
| **驿裂** | 中心 → 云篆洲·芜洲 | 无籍驿所在 | 最稳定，商队常走；云篆洲人叫它"西裂" |
| **北裂** | 中心 → 太荒 | 兽潮通道 | 最狂暴，兽群会借道 |
| **东裂** | 中心 → 铁枢 | 数据盲区 | 机械会"通灵" |
| **南裂** | 中心 → 灰原 | 白骨原 | 旧战场，律蚀最重 |
| **雾裂** | 中心 → 无言乡 | 不可测 | 地图在这里失效 |

### 3.2 裂缝的三种状态

| 状态 | 表现 | 写作用途 |
|---|---|---|
| **静** | 规则稀薄但稳定 | 安全通道，收过路费 |
| **涌** | 规则突然变浓 | 力量暴涨，也容易失控 |
| **啸** | 两域规则正面相撞 | 天灾级事件，开业劫首选 |

### 3.3 无主墟

- 五裂交汇处，规则最乱。
- 物理法则时灵时不灵：火可能不热，刀可能不割。
- **不许在这里打斗**——不是规矩，是常识。

## 4. 交通网络

### 4.1 五种交通方式

| 方式 | 速度 | 覆盖 | 成本 | 风险 |
|---|---|---|---|---|
| 步行 / 马车 | 50–80 里/日 | 全域 | 低 | 劫匪、兽群 |
| 驿道马车 | 100 里/日 | 云篆洲、辉庭 | 中 | 关卡抽税 |
| 铁路 | 300 里/日 | 灰原—铁枢、灰原—蒸枢 | 中 | 断轨、劫车 |
| 飞空艇 | 600 里/日 | 蒸枢、铁枢、云篆洲 | 高 | 风暴、失事 |
| 地下管道 | 250 里/日 | 畸城—灰原—铁枢 | 低 | 塌方、被收"管费" |

### 4.2 主要干线

| 干线 | 起点 | 终点 | 耗时 | 归属 | 剧情价值 |
|---|---|---|---|---|---|
| 灰铁线 | 灰原·铁棺城 | 铁枢·边陲站 | 2 日 | 横贯铁路公司 | 客栈进货主通道 |
| 灰蒸线 | 灰原·盐井 | 蒸枢·六城灰仓 | 2 日 | 私煤党 + 铁路公司 | 煤荒冲突 |
| 云港航线 | 蒸枢·云港 | 云篆洲·中州 | 1 日 | 飞空艇商会 | 急件、贵客 |
| 朝圣道 | 辉庭·白冠城 | 云篆洲·芜洲渡口 | 5 日 | 圣廷 | 朝圣者客源 |
| 暗管 | 畸城·下层 | 灰原·骨市 | 2 日 | 畸城帮派 | 走私、逃亡 |
| 无籍驿道 | 无籍驿 | 云篆洲·驿前镇 | 半日 | 无主 | 主角日常 |

### 4.3 交通的三个真相

1. **所有干线都绕开无主墟**，没有人敢直线穿越。
2. **铁路公司收"路权费"，飞空艇商会收"空权费"，畸城帮派收"管费"**——三种过路费，是三条供应链成本。
3. **雾裂没有路线**，所以无言乡的客人"什么时候到"取决于故事需要。

| 域 | 独有资源 | 稀缺资源 | 主要进口 |

| 云篆洲 | 灵药、符箓、灵脉 | 精钢、机械 | 钢材、机械、香料 |
| 铁枢 | 算力、义体、稀有金属 | 灵材、燃料、粮食 | 灵材、燃料、粮 |
| 灰原 | 废铁、旧兵器、弹药 | 水、粮、药 | 粮、药、酒 |

| 畸城 | 药剂、抑制剂、情报 | 粮、净水 | 粮、水、原料 |
| 无言乡 | 规则碎片、替身 | 活人、香火、纸 | 活人、香火、纸 |

### 6.1 三条命脉

1. **水**：灰原与畸城最缺。无籍驿那口井，是全书最重要的资产之一。
2. **粮**：蒸枢、铁枢、畸城都靠进口。谁卡粮道，谁就能逼人上桌。
3. **煤**：蒸枢的命，灰原的货，铁枢的筹码。

### 6.2 资源冲突点

- **白骨原煤矿**：蒸枢要，灰原占，铁枢想控。
- **芜洲灵脉**：已枯，但"旧灵脉"仍有残值，宗门不死心。
- **裂口药源**：畸城的抑制剂原料，只有裂口深处有。
- **南溟渔场**：辉庭与海盗的长期摩擦。

## 7. 气候与季节

### 7.1 四季

| 季 | 时间 | 特征 | 影响 |
|---|---|---|---|
| 开春 | 1–3 月 | 融雪、兽群北迁 | 太荒兽潮小高峰 |
| 长夏 | 4–7 月 | 季风、海雾 | 辉庭航线繁忙，灰原尘暴 |
| 收秋 | 8–10 月 | 粮价最低 | 客栈囤货季 |
| 锁冬 | 11–12 月 | 北寒、煤价最高 | 蒸枢煤荒，铁枢限电 |

### 7.2 特殊天象

- **雷暴季（太荒）**：规则自我修补，血脉会突变。
- **海雾（辉庭）**：船会"多走一天"，实际上是规则的错位。
- **尘暴（灰原）**：能见度为零，商队靠铁轨摸路。
- **酸雨（畸城）**：一周三次，屋顶必须铺铅。
- **无四季（无言乡）**：永远是黄昏。

## 9. 新增域落位规则（扩展协议）

### 9.1 五条硬规则

1. **只能落在六个槽位之一**，不许直接插进八域核心。
2. 若必须放在中心，只能用"**漂移飞地**"或"**裂缝口袋**"解释。
3. 新增域必须写明**邻接谁**、**到无籍驿怎么走**、**耗时多少**。
4. 新增域不得改变既有域的面积与坐标，只能"挤压错律带"。
5. 每次扩展只加 **1–2 个域**，并在地图上留出新的空白。

### 9.2 落位三步

```
选槽位 → 定邻接 → 定交通
```

- **选槽位**：陆上边缘 / 海外 / 地下 / 空域 / 沉眠。
- **定邻接**：至少接一个已存在域，否则商路不通。
- **定交通**：必须给一个"到无籍驿"的方式与耗时，否则客栈写不进去。

### 9.3 反例（不要这样加）

- 在云篆洲与铁枢之间硬塞一个新域 → 破坏既有距离。
- 在无主墟中心加一个"隐藏王国" → 违背"规则最乱"的设定。
- 加一个"什么都能去的传送门" → 让所有距离失效。

## 10. 地图数据模型（给未来的互动地图）

新增域时，只需在数据表里追加一条，前端即可渲染。

```json
{
  "id": "D09",
  "name": "示例域",
  "center": [9.0, 9.0],
  "radius": 1.0,
  "layer": "surface",
  "neighbors": ["灰原", "辉庭"],
  "access": {
    "toInn": "海路 3 日 + 陆路 1 日",
    "risk": "海盗、海雾"
  },
  "status": "candidate"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 与注册表一致 |
| name | 是 | 域之名 |
| center | 是 | 方格坐标 |
| radius | 是 | 影响范围（格） |
| layer | 是 | surface / underground / sky / overseas |
| neighbors | 是 | 至少一个 |
| access | 是 | 到无籍驿的方式与耗时 |
| status | 是 | candidate / dormant / active |

> 未来的 HTML 互动地图直接读这张表，不需要改渲染逻辑。

## 12. 写作检查表

写任何涉及地点与路程的情节，过这五问：

1. 这个地方在哪个域的哪一侧？
2. 到无籍驿要走几天？走哪条线？
3. 这个季节能不能走？
4. 路上要交几次过路费？交给谁？
5. 这条线出过什么事？

五问答不全，地理就是假的。
